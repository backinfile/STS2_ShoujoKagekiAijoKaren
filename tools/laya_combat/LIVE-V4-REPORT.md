# 英文固定通用策略测试

日期：2026-09-20。正式版 v0.107.1，Karen 进阶0，multilingual checkpoint，CPU。

## 改动

从 STS1/STS2 社区讨论提炼固定英文 `strategy.txt`，不包含角色、卡牌、遗物或敌人的专用打法。来源和取舍见 `STRATEGY-SOURCES.md`。策略运行时保持不变；每次读取新的状态，日志保存策略 SHA256。

简单规则增加显示数字的算术摘要：费用后的能量、扣除格挡后的伤害、数值斩杀、格挡的边际收益。未知效果保留原文，不模拟特殊触发，不强制覆盖模型选择。正文压缩了重复的动作名称和算术措辞。

## 结果与限制

- 22 项单元测试通过，涵盖合法动作、状态变化、选择索引、概率映射和保守算术。
- 英文简单斩杀样本仍选择结束回合。加入摘要和候选简短说明也未纠正；分布置信度不是正确率。
- 第4层 Seapunk 战斗开始时玩家49血、敌人44血。模型连续两回合直接结束回合，玩家49→38→30血。
- 第一轮运行在第2回合因1037-token输入停止；压缩重复信息后可处理该回合，但第3回合仍达到1025 tokens，超过1024上限，再次停止。没有截断输入或重复发送动作。
- 战斗尚未完成，目前停在第3回合玩家行动阶段。原始日志 `logs/v4-live.jsonl`，最终快照 `logs/v4-live-result.json`（本机忽略文件）。不能把这次测试算作胜利或完整败局。

固定策略符合归纳的社区经验，但未证明当前模型能执行它，不能宣称提示词带来了策略提升。下一步应优先做独立的英文决策样本评测，再考虑训练战斗专用 checkpoint；输入层应进一步无损合并重复卡牌描述并验证预算。继续扩充策略文字会加重长度问题。
