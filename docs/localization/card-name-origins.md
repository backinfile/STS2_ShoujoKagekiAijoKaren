# 爱城华恋：卡牌名字里的《少女☆歌剧》

华恋的卡名里藏着歌曲、台词、舞台装置，也有舞台少女们的练习与日常。这份说明按原作情节整理，方便你在打牌时找回熟悉的场面。

> **包含 TV 动画及剧场版结局剧透。**
>
> 部分对应来自卡名、卡图与剧情的对照；尚不能确定的地方会注明“可能”或“待确认”。

## 歌曲里的卡名

### 《Star Divine》

这组卡名与《Star Divine》的标题和歌词高度吻合：觉悟、命运、本能，以及向前开拓的意志，都能在歌中找到对应。

| 卡名 | 对应内容 |
| --- | --- |
| 神圣星辰 | 很可能取自歌曲标题《Star Divine》。 |
| 以觉悟的名义 | 对应以觉悟为名的剑这一歌词意象。 |
| 命运与本能 | 对应歌词中的命运与本能。 |
| 命运的齿轮 | 对应已经开始转动的齿轮，可理解为对歌词意象的概括。 |
| 开拓星辰 | 对应歌曲中开拓前路的呼喊。 |

想重温这组意象，可以查看[《Star Divine》歌词](https://utaten.com/lyric/mi17091310/)。

### 《星々の絆》——华恋与 Banana

TV 第 9 话中，华恋与大场奈奈交锋。这首歌把不断变化的星空与少女之间的羁绊联系在一起。

| 卡名 | 对应内容 |
| --- | --- |
| 星星串起了我们的友谊 | 高度对应星星连接彼此羁绊的歌词。 |
| 昨日夜空 | 很可能对应昨日与今日星空的对照；卡图也是华恋与奈奈的战斗。 |

参考：[《星々の絆》歌词](https://www.uta-net.com/song/257188/)。

### 《スーパー スタァ スペクタクル》——奔向下一个舞台

剧场版终战中，小光呼唤华恋，华恋再次站上舞台。这几张牌与歌曲的关键意象相呼应。

| 卡名 | 对应内容 |
| --- | --- |
| 燃烧吧燃烧吧 | 对应歌曲中燃烧、燃尽的呼喊。 |
| 过去与未来 | 对应歌词对过去、未来与当下的连接。 |
| 下一个舞台 | 既出现在歌曲中，也出现在华恋的登场宣言中。 |
| 唤醒 | 可能对应小光呼唤华恋醒来的段落，具体取名出处待确认。 |

参考：[歌曲歌词](https://www.uta-net.com/song/305228/)、[终战台词整理（观众整理）](https://note.com/zero_kakugo/n/n3df553411fca)。

## TV 动画：约定、Revue 与终幕

### 东京塔下的约定

**水族馆、东京塔下、约定之塔、我们的约定**，可以联系到 TV 第 4 话：华恋寻找小光，沿着水族馆的线索穿行东京，最后两人在东京塔附近重新确认约定。“约定之塔”也对应这一话的标题。[第 4 话场景记录](https://homuhomuhiro.hatenablog.jp/entry/revuestarlight/anime4)

**命运交换之日**则指向更早的起点：幼年的华恋与小光观看《Starlight》，从此将彼此与舞台联系在一起。官方剧情介绍也使用了“交换命运”的表述。[官方剧情资料](https://bushiroad.com/media/93b560dfc6051f1b)

参考：[Revue 与集数对照](https://www.setandset.com/archives/revuestarlightrevue.html)、[第 5 话棒球演出](https://anime-tip.com/sahplant/revuestarlight/8038)、[双人 Revue 与 Position Zero 介绍](https://tocage.jp/pages/1541392151.html)。

**背靠背、双人舞**也很容易让人想到华恋与小光共同战斗、共同演出的姿态，目前还不能确定它们取自哪一句台词。

### 《Starlight》与摘星

| 卡名 | 对应内容 |
| --- | --- |
| Starlight第一幕、Starlight第二幕、Starlight第三幕 | 以戏中戏《Starlight》为主题。卡牌的三个阶段未必等同于原作正式的幕结构。 |
| 星罪 | 原作终盘的 Revue 名称与戏中戏用语，也出现在《スタァライト》歌词中。 |
| 摘星 | 对应摘星的 Revue，以及戏中戏追寻星光的主题。 |
| "宽恕" | 对应戏中戏关于摘星、罪与宽恕的叙述。 |
| 两人的梦想 | 高度呼应华恋与小光共同演出《Starlight》的梦想，歌曲中也有相应语义。 |
| 星光闪耀之时 | 卡图是两只手伸向星光，与共同摘星的终幕相呼应；卡名原句待确认。 |

参考：[《スタァライト》歌词](https://utaten.com/lyric/mi18100419/)、[戏中戏分析](https://deji-chan.com/post-318)、[终幕场景分析](https://anime-tip.com/sahplant/revuestarlight/9227)。

### 不接受这个结局

TV 第 12 话，华恋不接受既定的悲剧，让故事在终幕之后继续。

| 卡名 | 对应内容 |
| --- | --- |
| NONNON哒哟 | 对应华恋否定既定结局的表达。 |
| 我们犯下的罪过 | 对应克莱尔背负罪过、留在塔中的故事。 |
| 续演 | 呼应终幕之后继续演出的段落。 |
| 续写 | 可以理解为华恋为悲剧写出新的后续。 |
| 命运舞台的再生产 | 对应终盘舞台随新的故事而再生产。 |
| 约定之塔桥 | 有明确的舞台装置名称「約束タワーブリッジ」：东京塔成为连接两人的桥。 |

参考：[第 12 话剧情分析](https://nato.hateblo.jp/entry/2020/02/18/210000)、[约定之塔桥画面与说明](https://anime-tip.com/sahplant/revuestarlight/9227)。

**永无结束的命运舞台**的卡图是小光独自站在层叠的舞台上，更接近她在 TV 终盘反复赎罪的处境。这里的循环应优先联系小光的舞台。[终盘舞台分析](https://ameblo.jp/kesutora/entry-12419315180.html)

## 剧场版：华恋为什么站上舞台

| 卡名 | 对应内容 |
| --- | --- |
| 为什么要离开？我的朋友 | 高度对应电影开头排练的戏中戏《遥远的黄金乡》：华恋所演的角色挽留朋友。 |
| 迈向那个舞台 | 对应回忆中幼年华恋向小光发出的邀请。 |
| 世界上最空虚的人 | 对应华恋形容自己空虚的台词，编剧活动记录也专门提到过这一句。 |
| 投下燃料 | 很可能对应长颈鹿、燃料与列车继续前进的段落。 |
| 歌唱吧舞蹈吧互相争斗吧 | 高度对应剧场版开场宣言；相关原文带有彼此争夺的意思。 |
| 最后的台词 | 华恋终于理解自己为何站上舞台，必须向小光说出最后的台词。 |
| 用你的闪耀贯穿我吧 | 小光对华恋说出的台词，也是剧场版的官方宣传语。 |

其中，**空壳、觉醒形态**与华恋的空虚、重生形成主题上的呼应；这两个名字尚未确认是原作对某种状态的正式称呼。
