# B03按攻击语义重审

用户反馈出场的群攻读感不明确，并拒绝蓄力亮芯。12张牌原生目标和结算保持原样，本轮重做其表现。

| 卡牌 | 实际效果 | 重做表现 |
| --- | --- | --- |
| 蓄力打击 | 单体1击，降力量 | 短收剑后压下的一道斩痕 |
| 上挑 | 单体1击，虚弱/易伤 | 从目标下方挑至上方的刀路 |
| 永无结束的命运舞台 | 单体1击，可无限升级 | 单道重斩，成长只增加封顶宽度 |
| 旋转 | 单体1击，移牌成长 | 一次有方向的回旋剑路 |
| 出场 | 全体3轮，升级4轮 | 每轮一份覆盖敌方阵列的横扫，逐目标短命中 |
| 神圣星辰 | 单体2击 | 两道交叉剑路，第二击收束成短星芒 |
| 对峙 | 单体3击，升级4击 | 目标附近的连续短刺 |
| 回击 | 全体3轮 | 每轮一份覆盖全阵列的反向回斩 |
| 星星串起了我们的友谊 | 单体1击，致命给奖励 | 轻斩，真实击杀后一次短闪 |
| 以觉悟的名义 | 单体1击，真实伤害转格挡 | 斩击后短剑痕回收，格挡由真实原生反馈确认 |
| 勇气打击 | 全体1轮，生成侧身入塔 | 一次覆盖全阵列的横切，保留真实生成移牌 |
| 落地 | 全体1轮，生成回击入塔 | 一道整体下压的低位冲击，保留真实生成移牌 |

4张群攻使用敌方范围作为主动作锚点，每轮只创建一个波次，逐目标回调不重复主动作。8张单体只在实际目标附近表现。起势沿用角色原地小幅动作，蓄力亮芯、跨场直射线及独立盾形图标移除；星芒只用于神圣星辰/真实致命。所有剑路有显现方向和短收尾，低档保持范围与轮数，减少分段及重绘频率，关闭/Instant沿原生反馈。

双版本逐卡实录、三小组前后视频及本轮定向结果见[重做验证](../testing/ordinary-attack-semantics-redo-2026-10-30.md)。上一版包及录像保留为改前。

用户后续要求修正整体挥剑方向，当前实现以近侧低起、朝敌方高收为首刀，多段上下交替且始终向敌方送出；详见[方向修订](../testing/ordinary-attack-direction-2026-10-30.md)。
