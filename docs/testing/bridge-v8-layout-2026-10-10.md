## 调整

原卡面两座塔的主体顶端高度接近，横桥较平缓地连接两塔上部。V7 左塔顶被裁出画面，右塔贴边，横桥跨度、倾斜偏大。V8 将两塔收回画内，补全可见塔顶，并降低桥的落差。1280×720 下，塔顶中心约在 x=260 / 1020、主体顶缘约在 y=127 / 140；横桥从左塔约 (320,210) 连接到右塔约 (980,285)。这些为画面估计位置，不是对原动画三维相机的测量。

旧素材的边缘被裁切，无法仅移动而不露出切口，因此使用内置 imagegen 重画完整布景，保存为 [stage-v8.png](../../images/vfx/bridge/stage-v8.png)。两次[完整提示词](../design/rare-vfx/bridge-v8-layout-prompts.txt)保留：第二次修正首图右塔偏低、内侧面变窄的问题。最终 1672×941 RGBA，69.3003% 像素完全透明，原样复制、无损导入、mipmap 与 alpha 边缘修复。图中仍保留右侧外壳向外绕行和桥身插入内侧面的连接；不是旧素材的像素级平移，局部形体和接头细节随重画改变。

运行时整幅布景等比缩放至原全画布适配比例的 0.85，舞台偏移 (+75,+55)。原来的独立右塔覆盖层及入口遮罩不再使用，接头已绘入完整布景。底端统一羽化，灯、光尘和桥上红灯随新位置校正。真实角色、敌人、卡牌与 UI 保持原位并在布景前方；瀑布巨人的身体会遮住部分右侧接头。出牌规则、0.48 秒入场等待、实际结算后的 0.45 秒退场保持不变。
