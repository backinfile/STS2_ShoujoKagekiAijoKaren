# 燃烧吧燃烧吧：尺寸跟随与重启优化

本轮延续最后的台词工作树，仅优化已有燃烧特效，等待用户查看后再继续。

## 保留与修改

保留老 Mod 复刻的 Wrath 火星、旋转红雾、贴图、颜色、粒子寿命与发射节奏；保留燃烧模式、抽牌升级、红色牌框和消耗规则。本轮不增加新的大型演出或音效。

- 以角色 `Visuals.GlobalTransform` 的两轴长度构建正向全局变换，位置仍跟随 `VfxSpawnPosition`。生成范围、粒子大小及上升距离一起适配人物尺寸，避免父节点重复缩放；角色翻转或旋转不改变火焰向上的方向。
- 保存停止 Tween，Restart 先取消旧淡出，Stop 幂等，退出树清理 Tween。
- 管理器先查本次角色节点，拒绝复用其他角色或已排队删除的节点；停止后重启可重新找到仍在淡出的同一节点。
- 同类粒子共享加色材质，避免每次出生创建一份材质；不改变混合方式。

测试插件命令 `burn_vfx check` 校验火焰节点唯一、存活、不透明、有粒子，比较位置和缩放，要求坐标轴保持正向竖直。最大位置误差约 0.000061，最大缩放误差约 0.000000060；`burn_vfx cycle` 通过真实管理器触发停止与重启。命令在 `tools/promise-transform/BurnVfxCmd.cs`，配合已有 `promise_transform` 使用。

正常角色实际轴长为 0.9，缩小后为 0.45，放大后约 1.35，火焰对应一致。已查看两版缩小/翻转截图；这些验证画面不进入交付视频。

正式版启动阶段出现 `Dev console used before being created` 输入异常；测试版 Common 预加载出现一次 `Invalid Task ID`。本次战斗及变形、重启段未检出新异常，不将整份日志描述为无错误。未做多人、完整矩阵或专门的旧角色跨房间缓存复现。

## 交付与证据

主仓库成片：`artifacts/vfx-review/burn-2026-09-29/burn-preview.mp4`。约 12 秒，1280×720、30 fps，原速、有游戏进程音轨，右上角分段说明开启、抽牌、牌面查看。原音频峰值 -26.6 dB，成片做 8 dB 增益。录制时保持普通窗口，结束后恢复设置并最小化。

工作树 `artifacts/burn-vfx/` 保存录制脚本、两版原片、状态、移牌截图、变形检查及日志。首次测试版脚本在录制完成后使用 Python 复制路径失败，随后用 PowerShell 复制已完成的原片，并独立补做全部变形与重启检查；没有把脚本提前中止当作全部验证通过。

开发环境中的临时测试插件在验证结束后移除。用户确认前不继续下一张，不合并 main。
