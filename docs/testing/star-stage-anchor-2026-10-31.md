# 星光舞台定位修正

本次移到华恋前上方的摆放已按用户反馈撤回，当前恢复原播放区上方并保持固定，见[原位置恢复与视频](star-original-position-2026-11-01.md)。本页保存历史定位对比。


2026-10-31，基线670440c。用户指出“星光中的特效怎么跟着卡牌走了”。

原实现每帧读取播放卡牌的Frame顶部，给整组星列定位，因而卡牌进出、缩放和重播也带动星列。现改为施放时记录华恋舞台位置，聚拢与星列固定在前上方。真实卡牌位置只用于逐次飞星的终点；卡牌自身短亮沿用原实现。

仅修改NKarenStarVfx，另外408份C#源码保持。星光形状、星点/20颗完整档散点、颜色、亮度、时长参数、真实规则及梦想演出均保持。
