# 觉醒形态：回合抽牌风场加速与原版快速模式

用户要求回合开始抽牌时加速风场，分别测试普通速度与游戏本体快速模式。

## 实现

- KarenFormPower.AfterCardDrawn 仅在 fromHandDraw 且卡牌属于能力拥有者时触发，不在 ModifyHandDraw 这类可能被预览调用的查询中播放动画。
- 延迟回调再次检查能力、角色归属和有效风场，防止移除后残留的回调激活旧特效。
- 一张实际抽出的牌刷新同一阵风的 0.55 秒保持时间；不按张数累加时间或速度。速度用真实时间约 0.15 秒从 1 倍升至 2.8 倍，最后一张之后保持 0.55 秒，再用 0.5 秒回落至 1 倍。
- 已存在的风线和新生风线使用同一个倍率，位移、动画寿命和生成节奏同步变化，保持原有风场风格与屏幕范围。没有额外 await、抽牌延时或 BGM 重播。

## 原版速度设置

测试插件 `native_speed` 直接设置 SaveManager.Instance.PrefsSave.FastMode 为 Normal 或 Fast，与原版 NFastModeTickbox 相同。未使用 MCP Instant，Engine.TimeScale 始终为 1。每轮结束后恢复原设置。

`form_surge watch/report/idle` 通过 SceneTree.ProcessFrame 采样实际风场倍率。首次探针采用普通测试程序集的 Node._Process，未接入 Godot 源生成，得到 0 个采样帧，因此该次不计为通过；改用原生 ProcessFrame 信号后，四组均取得数百帧采样并通过。测试插件不会随 Mod 发布。

## 风场音效试装（2026-09-30）

用户选择第一个候选后，在 NKarenFormVfx.PulseDraw 接入原版 event:/sfx/characters/ironclad/ironclad_whirlwind，volume=0.5。每个风场节点记录已播放的 CombatState.RoundNumber，同回合的十张牌只调用一次；Restart 不清除回合记录，避免同回合恢复节点时重响。音频走原版 SfxCmd，跟随 SFX 设置，无新资源、无额外等待。

两版构建各 0 错误、23 个已有警告。正式版与测试版各完成 Normal/Fast 单人实录：风速峰值 2.8，结束回到 1，回合抽牌后及普通补牌后手牌模型/节点均为 10/10，普通补牌峰值为 1。四组均保存操作前后截图与状态，抽样查看画面正常。日志中有临时测试插件使用旧 dependencies 格式的启动提示，无战斗异常或 FMOD 事件缺失。

本轮证据：工作树 artifacts/form-sfx-vfx/。主目录 artifacts/vfx-review/form-sfx-2026-09-30/form-wind-sfx.mp4 为 beta Normal（前 12.4 秒）＋ stable Fast（后 9.23 秒）有声实录。成片统一增益 +8 dB，不改变声音比例；峰值 -19.1 dB，无超过一秒停帧。尚未做多人、完整机制矩阵、满手禁抽等测试；这次为音效试装，等待实际听感反馈，不作为完整兼容验收。

### BGM 录音结论更正

用户追问 BGM 后发现：上述 playing=true 只能证明播放器运行，不能证明声音可听。静音时施加形态会将播放器 VolumeLinear 初始化为 0，解除静音不会更新它。另有 MuteInBackground 在录制窗口失焦时静音总线。因此此前视频不能作为 BGM 与风声混合效果的验证。

补充探针返回播放器音量和播放位置；测试版两次复现静音启动后 playing=true、volume=0。正确录制先关后台静音（测试结束恢复）、重新应用窗口与音量以结束已有静音渐变，然后在非静音状态打出形态：volume=0.125，播放位置递增。此轮修正录制流程，没有修改运行时音乐音量同步行为；静音启动音乐后解除静音的缺陷仍待修复。

新成片为主目录 artifacts/vfx-review/form-sfx-2026-09-30/form-bgm-and-wind.mp4，21.33 秒，包含打出形态前、BGM 切换和下一回合风声。直接游戏进程采音，无后期配乐；仅统一 +8 dB。与原曲第 3～4 秒片段的波形相关系数 0.732（录像偏移 6.889 秒），证明实际采入原曲。峰值 -18.5 dB，无超过一秒停帧，手牌模型/节点 10/10。这段补录仅测试版 Normal，未补录正式版或多人。
