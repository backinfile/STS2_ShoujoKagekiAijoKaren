# 约定星座特效（2026-09-26）

## 表达

约定牌堆的常驻星星由随机公转改为角色上方的开放弧形星列。普通模式显示实际数量；最多绘制十个代表星位，超过十张仍显示精确数字。每张卡牌在当前战斗中绑定稳定星位，少量移入移出不会让已有星星重新排队。

星位作为原生 `PileTypeExtensions.GetTargetPosition` 的约定牌堆返回值，卡牌飞入、取回均衔接同一个位置。移牌期间从真实 `NCard` 位置采样短金色轨迹，卡牌到达后点亮星位；取出时星位淡去，星光随卡牌展开。没有重新接管手牌容器、节点创建销毁或规则层移牌。

进入/离开不再共用旧 `IsOrbiting` 开关，移除旧的逐星 Polygon2D/CPU 粒子类，避免退场 Tween 与逐帧位置更新竞争。常驻星位集中绘制，复用弧线、星形、清理和去重缓冲；轨迹每张最多十二个采样点。

- 普通：暖金星列与精确数量。
- 燃烧：红金星列，保留现有燃烧表现。
- 过去未来：移牌时增加青白弧线脉冲，保留已有模式光环。
- 无限强化：显示 ∞，使用真实续演库存，不再伪装为二十张。
- 虚空：显示菱形模式标记并隐藏代表库存的星列；移牌继续使用原生抽牌堆目标。
- 无限与虚空同时存在时，文字优先显示 ∞。
- 战斗结束立即清理；延迟刷新校验战斗状态与房间，防止上一战的任务污染下一战。

## 本轮边界

原生卡牌的曲线、速度和快进设置继续由游戏管理。星光叠加跟随真实移动，不新增等待；尚未替换原生卡面着色或制作专门的卡面溶解 shader。十张以上星位是代表点，不暗示一星仍等于一卡。模式专属的旧燃烧/过去未来特效仍然独立存在。

## 复测与录像

在具备双版本游戏快照的工作区运行：

```powershell
pwsh -NoProfile -File tools/update_dev_mcp.ps1 -LoopbackOnly
pwsh -NoProfile -File tools/test_promise_visuals.ps1 -Environment stable -Record -Showcase
pwsh -NoProfile -File tools/test_promise_visuals.ps1 -Environment beta -Record -Showcase
pwsh -NoProfile -File tools/test_dev_matrix.ps1 -Suite full -UpdateMcp -LoopbackOnly
```

`-Record` 使用 KarenSTS2MCP 的游戏视口录制接口，保存 1280×720、30fps、无声 MP4。`-Showcase` 用真实《闪避》效果逐次储存十三张《对峙》，再通过《约定之塔》批量取回，最后依次展示燃烧、过去未来、无限和虚空模式。每个阶段保存截图、状态，执行 `karen_check_hand`；原有单张移牌断言仍保留。

结果写在本轮工作区 `artifacts/test-promise-visuals/`，完整联机矩阵在 `artifacts/test-matrix/`。每次录像必须等待接口报告 completed，再复制成最终 MP4；失败演示也尽量完成封装供排查。
