# B03挥剑方向修订

本页保留b727ef1方向修订证据；用户后续要求细化其余10张，当前结果见[逐卡细化](ordinary-attack-ten-card-refinement-2026-10-30.md)。
日期：2026-10-30。用户反馈“线的方向也不太对”，并明确为“整体挥剑方向不对”。本轮以e3a16f6包为改前，仅修改普通攻击演出partial的刀路与显现进度，角色幅度和卡牌规则保持原样；当前供视频复核，工作树保留。

## 改动

| 卡牌 | 当前刀路 |
| --- | --- |
| 蓄力打击 | 近侧低起，斜向敌方高处收刀，移除原先下压方向 |
| 上挑 | 从下方持续前送到目标上方，控制点与末端都沿前向排列 |
| 永无结束的命运舞台 | 单道低起高收重斩，宽度继续封顶 |
| 旋转 | 从近侧下方绕向敌方，再沿前侧挑高收回 |
| 出场 | 整排近向远三轮斜扫，上挑/下斩/上挑，升级四轮 |
| 神圣星辰 | 首刀上挑、第二刀下斩，两刀均朝敌方送出 |
| 对峙 | 保持向敌方连续短刺，减少初帧已出现的长度 |
| 回击 | 三轮都从近侧迎向敌方，上下交替 |
| 星星串起了我们的友谊 | 保持轻上斩，缩短初帧刀路，真实致命分支保留 |
| 以觉悟的名义 | 首刀上挑；实际格挡后的回收剑痕保持回到角色 |
| 勇气打击 | 覆盖敌方整排的一次近向远上斜扫 |
| 落地 | 整排刀路同时下压，去掉横向生长动作 |

先录蓄力、上挑、出场三张样片并查看连续帧，再录双版本12牌。普通刀路从18%长度开始，在0.10秒内向前展开；群攻按敌方整体中心确定高低，而非串联各敌人中心造成朝向倾斜。左侧目标镜像刀路；测试夹具同时镜像角色和整组敌人，保持原场景范围。

## 定向结果

双版本构建、52段前后实录的包/视频/音轨/规则结果、16份生产源码指纹及资源清单80类/39共享准备者/167资源核对通过。[数据记录](ordinary-attack-direction-2026-10-30.json)保存逐例结果。4张群攻均用3个敌人；出场/回击分别27/36总伤害、各9次接触和3道主刀路，勇气/落地各18伤、3次接触和1道主刀路。每道群攻实际起止向量均确认从角色近侧送往远侧，首轮向上，后续上下交替；左侧出场三轮方向正确镜像。

人物姿态峰值9.75像素，节点、姿态与显示层级恢复。觉悟6伤/6格挡，蓄力力量下降3，上挑虚弱/易伤各1，勇气/落地各生成1张真实牌入塔，规则与前版一致。每例MCP手牌核对通过；两版勇气/落地移牌前后截图、正式版12牌接触/收尾帧及低档/左侧代表已查看。卡牌模型较e3a16f6无改动，继续保留此前对main的12模型归一化规则核对。

测试版改后Common预加载有2条历史同类原生Invalid Task ID，随后预加载完成并通过逐卡运行；出牌阶段未检出C#异常或Shader错误。本轮只跑方向相关最小范围，关闭/Instant、升级、成长、致命、重播、取消及NONNON粒子专项沿用前轮证据，本轮未重跑；完整矩阵、完整首次使用/帧耗时专项和Android未测。

最终包仅部署于本轮工作树隔离游戏。main保持fc16623，常用开发游戏和9个原目录文件保持原状；所有旧包、样片、原片、工作树及任务分支保留，当前待观感复核。
