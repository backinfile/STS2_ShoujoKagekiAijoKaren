# NONNON粒子层恢复

日期：2026-10-30。用户反馈：“为啥nonnon的例子特效没有了”，并确认指粒子特效。

原因是上一轮参考重做把卡牌入口从`NKarenNononVfx`换到`NKarenStageAttackVfx`的Sweep配置，尘屑、碎片及风粒子仍留在旧控制器中，新的横扫没有带上它们。完整档旧实录生成过旧控制器，新实录只有横扫节点。此前观察器只统计CpuParticles2D，旧粒子实际为画布手绘，原来的0计数没有覆盖这层。

本轮在横扫下接回旧控制器的粒子专层。它只绘制原来的粒子、碎屑与薄雾；刀光和命中仍由新横扫负责。人物继续使用约10像素的原地动作。粒子子节点随主演出释放，横扫的视觉尾部留足1.28秒粒子寿命，身体已在命中后正常复位，规则等待和结算沿原实现。

| 档位 | 粒子处理 |
| --- | --- |
| 完整 | 恢复旧版完整密度及薄雾 |
| 低 | 使用旧版四分之一采样，移除两片局部薄雾 |
| 关闭 / Instant | 不生成自定义横扫与粒子层 |

增加被动测试观察器`maxManualParticles`和`check_nonon_particles.py`。在本轮重新录制的064432f改前完整档中，检查器实际报错`NONNON particles: 0; expected enabled=True`，能直接捕获这次粒子入口缺失。

双版本构建、资源静态清单（80类/39共享准备者/167资源）及定向实录已完成，当前等待观感复核。生产改动限于旧粒子控制器的专层入口与横扫对子节点及尾部的管理。
