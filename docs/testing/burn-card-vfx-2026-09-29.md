# 燃烧抽牌：动态牌缘火焰

当前采用下文“角色同源红焰修订”；早期六帧火舌方案已被替换。

按用户反馈，移除燃烧抽牌强制设置 ShouldGlowRed 的分支，保留原版可打出高亮和闪耀即将耗尽的提示。升级、消耗及人物常驻火焰规则不变。

参考原版 Infection 的动态 OverlayContainer 结构，使用原版 `images/vfx/fire_impact/fire_burst_flipbook_1.png` 六帧火焰素材：牌缘火舌错开时间、独立循环，颜色由红橙过渡至亮黄；随卡牌本地坐标倾斜和悬停放大。没有复制感染牌的虫体图案，也没有改写卡牌边框材质。

## 生命周期

- 卡牌模型记录燃烧抽牌标记；只在手牌显示。
- 同时挂接 ReloadOverlay 和 UpdateVisuals。只挂 ReloadOverlay 不够：已有牌节点可能在初始化后才获得燃烧标记，而 Upgrade/UpdateVisuals 不重新加载原版覆盖层。
- 保留原版覆盖层及附加效果；每张牌最多一个独立燃烧层。
- 模型变更时丢弃旧层；OnFreedToPool 前立即 detach，再排队删除，避免节点池复用污染其他牌。
- `karen_check_hand` 增加每张手牌的覆盖层数量、归属和存活检查。

## 角色同源红焰修订

按用户最新反馈，卡牌改为直接复用角色燃烧效果的 `NKarenWrathParticle` 和 `NKarenStanceAura`，包括 glow_spark / exhaust_l 贴图、加色混合、红色至微粉色、上升拉伸、旋转和淡出曲线。删除上一版橙黄色六帧火舌及其独立 shader。人物特效代码不变。

卡牌采用 0.55 倍火星层、0.62 倍烟雾层；烟雾透明度收敛为角色效果的 45%，火星优先分布两侧并覆盖上下缘，避免遮挡文字。粒子 ZIndex 归零，随所属卡牌的本地覆盖层排序，不跨过相邻手牌。到手时预热少量粒子，立即可见；保留原有模型归属及节点池清理。

两版均重新编译通过（0 错误、23 个已有警告），定向复测四张抽牌升级、悬停、逐张消耗、补入普通牌与进入新战斗。覆盖层检查为 4 张各 1 个 → 空手 → 普通牌 0 个 → 新战斗 5 张各 0 个。已查看双版本悬停截图，实录及成片检查无异常停帧。未跑完整矩阵或多人。
