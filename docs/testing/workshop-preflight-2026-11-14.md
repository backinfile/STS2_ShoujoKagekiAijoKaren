# v0.2.0 工坊发布前测试（2026-11-13—14）

本轮使用 Karen v0.2.0、Core 1.9.3、BaseLib 3.4.8。正式版 v0.107.1 与当前测试版 v0.113.0 的完整矩阵、附加联机回归及特效门禁均通过，最终包已安装到本机 Steam。逐包 SHA-256、逐项结果与证据路径见 [机器可读清单](workshop-preflight-2026-11-14.json)。

测试版以 Core 1.9.3 的发行目标 v0.113.0 为准；旧开发说明中的 v0.111.0 不在该 Core 包声明的目标内，本轮未测。

同版本联机分别覆盖 Karen 主机 + Karen 客户端、Karen + 原版、原版 + Karen、原版 + 原版对照；双方轮流出牌、结束回合，用户目录、端口和日志相互隔离。主矩阵 72 张、转交专项 64 张移牌截图及两张冷恢复截图均已查看，动画结束后的 `karen_check_hand` 与可见节点一致。特效门禁的 48 张战斗截图也已查看；8 张过渡期黑屏截图已排除。特殊演出另存截图与影片播放器进度证据。

Core 当前规定同一次原生出牌及其重播共享一次闪耀预算。附加回归分别断言 `PlayIndex` 为 0、1、2，`PlayCount` 为 3，闪耀从 4 降到 3，仅转交一次且复制后仍为 3；拒绝分支保留原牌。旧测试按重播次数扣减的预期已更新，并保留对三次实际执行的独立检查。

两版各完成 306 项资源准备、30 批实际绘制和 593 次绘制调用；准备耗时分别为 1874.1123ms、1926.1752ms，重复准备为 0.0254ms、0.027ms。最终计时共 210 次播放，最高帧耗时 31.7478ms。32 张特殊演出截图已查看。BaseLib 的 5 个文件在两版主机、客户端缓存及 Steam 工坊来源中哈希一致，清单附有逐文件哈希。

首次测试版整组特效记录到“获得闪耀”首帧 36.7887ms，创建耗时 34.6912ms，同一帧有第 0、1 代 GC。独立冷进程三次播放最高 16.9859ms，随后整组冷进程复测也没有超过 33.3ms 的帧。原始长帧记录与两次复测均保留在清单中。

生产包由 Karen 游戏源码基线 `bc6ea96`、本次导出排除规则及 Core `aaca8c1` 构建。标准构建已确认引导/分支 DLL 与冻结候选一致，`core.requirements` 使用完整能力列表。修正的测试工具包括当前存档字段、原生重播预算、异步状态轮询和 Core 轮廓缓存探针；失效或探针设置错误的轮次不计入通过数量。

原始日志、存档、临时探针和截图位于已忽略的 `artifacts/workshop-preflight-20261113/`；公共清单仅保留相对路径及产物哈希。Steam 原包备份位于该目录的 `steam-backup/`。
