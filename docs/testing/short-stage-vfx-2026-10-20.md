# 门票、梦想与双幕 Starlight 表现修订（2026-10-20）

先使用内置 imagegen 生成门票、两人的梦想和第一幕各 A／B／C 三个方向的方案板。门票前两轮未采用；最终按“一次性短演出、结束完全消失”重新设计并选 C「丝带一闪」。梦想选 A「双星织光」；第一幕选类似 B 的星轨，同时明确不加常驻特效。

全部方案板、内置 imagegen 的完整提示词及门票两次追加提示词保存于 `artifacts/vfx-design-exploration-20261020/`。最终设计参考：`designs/ticket-round3-ABC.png`、`designs/dream-ABC.png`、`designs/act1-ABC.png`。它们用于设计比较，实际游戏效果由原生节点上的程序化丝光、星点和真实卡牌锚点绘制。

- 门票：短丝带掠过实际打出的卡牌，能力确认后退场。回合开始生成真实塔牌后，再由能力图标向该牌引出一段 S 形丝带和少量碎片；不再铺地面光路，不创建票框或悬浮常驻物。施放前奏 0.30 秒，回合前奏 0.14 秒，真实牌面可见后的卡牌装饰 0.48 秒内结束。
- 梦想：施放时一暖一冷两颗星沿细丝轨迹掠出，短演出结束即清理。回合结束时双星汇合成白色核心，沿本次真实生成的光辉模型交接，普通模式进入对应塔星，空虚模式交接到抽牌图标；删除旧宽幅梦想烟雾绘制。确认能力／生成结果与表现分开，仍使用原生命令返回的模型。
- 第一幕：五点短星轨依次亮起，施放结束后释放。真实闪耀牌触发时短星轨与细光掠向本地抽牌图标，仅给实际抽到的卡牌短促点亮；普通牌不触发，不注册额外常驻管理器。施放前奏 0.32 秒。
- 第二幕：光束展开区间从 0.02～0.48 秒缩短到 0.02～0.22 秒，脚灯接地从 0.40～0.52 秒提前到 0.18～0.26 秒。继续按 Normal／Fast 的既有时间缩放；同一个舞台仍持有完整出牌、三次重播及耗尽，未缩短它的所有权。

`KarenLightRibbon` 只向调用者拥有的层绘制短带，不创建独立粒子节点。新增表现均沿用现有房间归属和 `_ExitTree` 清理，不改写原生卡牌布局、缩放、材质或高亮。涉及真实卡牌的落点均核对当前可见模型。

## 针对性验证

正式版 v0.107.1、测试版 v0.111.0 分别使用隔离环境与端口 18757／18758，通过 KarenSTS2MCP 执行 `ticket,dream,dream-void,starlight-act1,starlight-act2` 五段真实流程。普通梦想单层、空虚梦想双层；第一幕包含普通牌不触发的对照。场景分别检查实际收益、手牌模型与可见节点、塔星身份、演出后所有层释放，以及第二幕的唯一跨重播舞台。

`StageProbe` 逐帧观察实际绘制使用的光束进度，记录首次展开和接地完成时刻；`benefit_scenes.py` 要求展开不迟于归一化 0.26 秒、接地不迟于 0.30 秒，保留帧采样容差。门票、梦想和第一幕在能力仍存在时另保存演出清空后的 MCP 截图与 Composition 状态，核对所有注册节点、前后景和 HUD 层为零。

证据目录为 `artifacts/short-stage-vfx-final-20261020/`；所有移牌前后保存 MCP 截图并执行 `karen_check_hand`。本轮是双版本专项单人实测，不运行完整单人／多人矩阵。

原始试录保留在 `artifacts/short-stage-vfx-20261020/`。录像审阅发现原生命令先返回卡牌模型、牌面随后可见，过短的入手装饰可能提前播完；最终版本给门票回返及第一幕抽牌分别记录真实可见牌面的起始时刻，至多等待 1.5 秒，牌面离手或超时均不伪造反馈。观察器记录 readyCards 和 cardVisualDelay，核对实际卡牌均获得可见反馈后再清理。

最终结果：两版各五段通过，各 27 次手牌核查一致、9 次演出清空核查通过，日志无意外错误。测试版启动预加载期间保留四条既有工作池 `Invalid Task ID`；正式版无该条目。门票回返与第一幕抽牌的实际模型及可见卡牌计数均为 1；普通牌对照未触发第一幕抽牌；空虚双层梦想实际生成两张光辉。第二幕首次展开到位分别观测到归一化 0.216／0.220 秒，三次重播索引与唯一舞台持有通过。

正式版第一幕第一次录像采帧率 14.50 fps，未用于交付；保存于 `diagnostics/stable-act1-low-fps/`，原日志为 `stable-run-01-godot.log`，仅重录这一段。最终正式版最低采帧 27.85 fps，测试版最低 29.42 fps，两版交付段落均零编码丢帧；时钟采样检查 PTS 严格递增。全部移牌前后 MCP 截图与选定演出帧、字幕均已查看。
