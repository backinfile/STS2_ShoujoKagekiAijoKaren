# 塔桥 V5：右塔螺旋外壳的绕轴朝向

历史记录：用户随后指出平整连接面应与桥轴垂直，V5 未表达清楚该结构关系；当前版本见 [V6 右塔连接面](bridge-v6-right-face-2026-10-09.md)。

2026-10-09。用户进一步明确：问题是“螺旋层绕塔身的朝向不对”，并非整根塔的画面倾斜。本轮仅替换右塔的螺旋面。

## 画面与接入

V4 的可见层缘呈向上拱起的近水平环线，左前缘重复暴露红色楔形缺口，读起来接近正对镜头的叠层套筒。V5 将正面的螺旋线改为向右下方绕行，接缝和断口退向右外侧，内侧轮廓更连续。这里只描述绘制后的可见朝向，不宣称测得或实施了某个精确的三维旋转角。

使用内置 imagegen，以 V4 透明素材和原卡面为参考，仅生成[右塔独立透明图层](../../images/vfx/bridge/right-tower-v5.png)，完整[提示词](../design/rare-vfx/bridge-v5-right-tower-prompt.txt)已保存。输出 1672×941 RGBA，95.4285% 像素完全透明，保持无损导入、mipmap 和 alpha 边缘修复。输出直接复制；未程序重绘图片。

`stage-v4.png` 没有修改，继续提供桥体和左塔。Shader 仅在最右侧按已有塔缘裁去旧右塔，再叠加新图层，避免重新生成桥体或左塔。两层共用入场时序、轻微视差与实际结算结束信号，退场约 0.45 秒，属于同一个 VFX 根节点。替换资源不可用时保留旧塔作为回退。

检查了接桥处和完整构图。生成图的下端比提示词要求更长，仍由已有羽化控制；螺旋层的投影间距也随重画有所变化。新图层右塔之外仅有 3 个 alpha=1 的像素，没有可见的桥或左塔内容。
