# 摘星、星罪、舞台光路与闪耀提示：2026-10-14 修订

临界提示、耗尽入堆和第二幕灯光已继续调整，最新实现见 [2026-10-15 专项](shine-motion-2026-10-15.md)。第二幕落点以背景场景地面为准，本页的“视口底部”是前一轮实现。

本轮接续 `bec1c74`，按用户要求先交付单独录像。原来的 [49 段全览](vfx-catalog-2026-10-14.md) 保留为前一轮历史记录，本轮视频对应新的实现 DLL。

## 修改结果

| 项目 | 本轮行为 |
| --- | --- |
| 摘星 | 被禁用遗物的星光飞向本地实际能量计数器中心，普通／升级均回能 2；升级禁用数仍为 1 |
| 星罪 | 星光飞向实际抽牌堆 `Icon` 中心，普通／升级均抽 3；升级禁用数仍为 1 |
| 第二幕打出 | 七束人物后方灯光与五束人物前方灯光延伸到视口底部；后方灰色底幕、光束间灰色楔形遮罩、底部灰幕和前方薄灰幕增强明暗 |
| 门票 | 从一串光斑改为连续收窄的地面透视光带；近端绑定角色足部右侧，向身后地面延伸；回返和手牌交接沿同一条路径 |
| 两人的梦想 | 移除自定义打出特效及其等待、收益观察；原生能力应用和 `DreamTrigger` 保留。实际生成光辉的时机仍为 `AfterSideTurnEnd`，没有把玩法改到回合开始 |
| 闪耀临界 | 提示从手牌跟随实际 `NCard` 进入队列／打出区，并贯穿打出和第二幕重播；耗尽时交接既有耗尽动画，回池仍由原清理补丁回收 |
| NONNON | 普通／升级本来就调用同一个 `NKarenNononVfx.Create(Owner)`，没有升级视觉分支；保留同款剑风，修正录像说明，升级仅改变数值 |

遗物发射点在替换节点前读取 `GetGlobalTransformWithCanvas`；根节点以逆 Canvas 变换绘制在视口坐标系内。每帧重新读取目的地实际变换，HUD 落点取消随机偏移。其他禁用遗物调用默认仍到角色，远端玩家不使用本地 HUD；节点在换场／战斗结束时释放。规则收益未新增等待。

第二幕前方灰幕使用普通混合并位于前方加色光束之前；后方灰幕和光束仍在 `BackCombatVfxContainer`。背景协调权重和整次重播／耗尽的预览持有流程沿用既有实现。

临界提示原先仅允许手牌模型、手牌显示，所以进入打出区立即隐藏。现保存手牌预告并允许 Hand／Play 显示，在已经递减闪耀的打出阶段按 0 判定耗尽，避免把正常 2→1 出牌误当作本次耗尽；自动打出也可按递减后数值判定。对象池复用时清理旧提示，保留原卡缘和星屑绘制。
