# 双版本游戏内测试记录（2026-09-23）

联机回归针对 [“修复多重卡牌未耗尽”任务](codex://threads/01a0c977-06d0-7fe3-bc0e-3d4eb7e40a48)。测试版约定牌堆最初在抽回手牌时抛出 `ArgumentOutOfRangeException`，堆栈从 `CardPileCmd.Add` 指向 `NCard.FindOnTable`。测试版游戏开始为该移动生成原生动画，但约定牌堆是自定义 `PileType`。现已在从约定牌堆移出时跳过该动画；修复后单人及 Karen/Karen 联机均通过。

| 跨版本主机／客户端 | 结果 |
| --- | --- |
| 正式版／测试版 | 连接失败；主机记录 `HandshakeTimeout`，客户端记录原因 13，仍留在选角阶段 |
| 测试版／正式版 | 连接失败；正式版客户端不能解析测试版初始网络消息，主机记录 `HandshakeTimeout` |

跨版本两种方向均未进入游戏，且客户端错误弹窗触发游戏本体 `SwitchExpressionException`，因此“正常提示并退出”**未通过**。这是不同游戏版本的网络协议行为；以上同版本联机和各版本独立加载结论不包含跨版本互联。未执行断线恢复测试，因为本次改动不涉及存档或断线处理。混合角色组合只检查基础联机与回合同步；约定牌堆和中途清场耗尽机制由 Karen/Karen 组合验证，未逐一在混合角色组合重复。全局移牌在约定牌堆移入/抽回路径运行，但未单独断言其所有触发回调。

本机详细日志保存在被 Git 忽略的 `artifacts/test-logs/`：`solo-*-shine-regression.log`、`mp-*-karen-*.log`、`mp-*-KAREN-KAREN-shine-regression-*.log` 及 `mp-cross-*.log`。日志仅属于本地测试环境，不随提交发布。
