# 塔桥 V6：右塔平面与桥轴的连接关系

历史记录：用户随后要求外壳继续转向右侧，桥身插入半塔；当前版本见 [V7 插入式接头](bridge-v7-inset-junction-2026-10-09.md)。

2026-10-09。用户指出“应该平整的一面与横向的塔桥垂直”。V5 只调整了螺旋层缘，内侧仍接近一条红色窄边，没有表达平整连接面。本轮按桥端正接平面的结构关系重画右塔。

## 素材与接入

- 右塔内侧改为可见的酒红色平面，朝向桥端；灰蓝螺旋外壳绕向右侧，层缘断面沿平面边缘排列。平面横向边线按桥端截面的透视方向绘制。这里是二维绘画对三维垂直关系的表达，没有以三维模型计算或测量精确旋转角。
- 使用内置 imagegen 一次生成[独立透明素材](../../images/vfx/bridge/right-tower-v6.png)，[完整提示词](../design/rare-vfx/bridge-v6-right-tower-prompt.txt)已保存。以 V4 整桥、V5 右塔和原卡面为参考；输出 1671×941 RGBA，90.0999% 像素完全透明。直接复制输出，没有程序重绘素材。右塔之外有 3 个 alpha=1 的像素，无可见额外图案。
- 继续使用未经修改的 V4 桥体与左塔素材。右塔独立图层按画布比例等比缩放，在 1280×720 舞台坐标下偏移 (+40,+15) 对齐桥端；保留无损导入、mipmap 和 alpha 边缘修复。
- 新图平面更宽，旧的按横坐标判定的羽化没有覆盖到内侧红面，首轮实机发现其下端伸入 UI 区域。最终为右塔独立图层统一应用底部羽化；修正后两版重新实测，截图已查看。首轮证据保存在 `stable-before-feather` / `beta-before-feather`，不作为最终画面。
- 灯光、音效、实际结算后的退场时机保持不变。两张素材同属每次出牌的根节点，共用结算结束信号；现有缺图回退保留。

生成器同时改变了右塔的可见宽度、层间投影间距和下端长度，运行时通过位置注册与羽化适配；不宣称只做了严格的三维刚体旋转。
