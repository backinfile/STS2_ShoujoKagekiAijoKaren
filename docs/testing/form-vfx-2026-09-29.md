# 觉醒形态：风场坐标与生命周期优化

按逐卡计划保留既有 horizontal_line 贴图、红褐色加色风场、右向左速度范围、生成节奏和 BGM，只优化实现。卡牌费用、虚无升级和抽满手牌规则不变。

## 修改

- 风场仍归属出牌者的角色节点以随战斗释放，但采用 TopLevel 和逆 CanvasTransform，在视口坐标中运行。修复把屏幕出生坐标减去人物位置后，又被父级变换二次作用的问题；人物缩小、翻转、移动不改变全屏风向。
- 发射高度从 15%–85% 收敛至 22%–65%，上下边界为 16%/73%，边界淡出，避免穿过底部手牌和顶部状态栏。这里约束粒子中心；贴图本身有柔和透明尾部。
- 粒子寿命按实际穿越距离和速度计算，避免固定 1.25 秒使慢风线中途消失；共用加色材质，宽高按同一视口比例缩放。
- 保存并取消停止 Tween，Stop 幂等，Restart 可取消淡出；管理器验证本次角色归属、排队删除状态和当前能力，防止延迟启动发生在能力移除之后。
- 从卡牌 OnPlay 移到 Power.AfterApplied 启动视觉，与音乐保持一致；AfterRemoved 使用 oldOwner 同时停止风场和 BGM。已有战斗结束清理继续保留。
