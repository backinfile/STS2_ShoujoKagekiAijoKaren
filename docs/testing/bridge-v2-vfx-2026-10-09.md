# 约定之塔桥 V2：制作与定向实测

2026-10-09。用户确认仰视塔桥的新设计后授权制作，并要求生成素材去除 AI 摩尔纹。按此前要求，只做本卡的双版本定向实测；没有运行完整测试矩阵。

后续修订：用户指出本版灯光不明显、固定 1.35 秒退场未等待卡牌结算。该问题已复现并修正，当前结果见[主追光与结算等待修订](bridge-resolution-vfx-2026-10-09.md)。下文是修订前的制作和检查记录，不作为生命周期已正确的证据。

## 最终效果

桥体改为独立绘制的红白桁架透明素材，用从近到远的灯光显出结构，并保留小幅视差；白塔只显示画面两侧的曲面。约 0.48 秒开始真实自动出牌，约 1.35 秒完成布景退场。角色、敌人、血条与手牌使用原游戏节点，新增图层在后景。空牌源只在真实来源短亮约 0.22 秒。

玩法仍是约定牌堆先批量移到 Play 再逐张自动打出；空虚模式继续使用原生抽牌与洗牌。单张追光由真实自动出牌事件触发，不生成装饰卡片。保留逐次出牌归属和战斗切换时的清理。

[最终有声实录](../../artifacts/bridge-v2/bridge-v2-with-audio.mp4) · [实际游戏关键帧](../../artifacts/bridge-v2/bridge-v2-keyframe.png)

视频来自测试版最终定向轮，1280×720、30 fps、H.264＋AAC。画面时长 8.50 秒，音轨 8.521 秒；原游戏音轨整体增加 10 dB，平均 -32.8 dB、峰值 -11.8 dB，无削波。MCP 确认为 `audio_source=game_process`。已经检查连续帧，正常入场、退场和出牌均有连续运动，尾部保留战斗静止画面。

## 素材与去摩尔纹处理

使用内置 imagegen，基于已确认的关键帧分别生成透明桥体和塔面，未把包含 UI 与人物的概念图贴入游戏。

- [桥体素材](../../images/vfx/bridge/bridge.png)：1672×941，RGBA，完全透明像素占 80.32%。以宽桁架、清晰三角支撑、少量厚接头代替概念图中的密集细肋和重复微纹理。
- [塔面素材](../../images/vfx/bridge/towers.png)：1672×941，RGBA，完全透明像素占 92.60%。保留宽曲面、少量接缝和干净的明暗过渡。
- [完整生成提示词](../design/rare-vfx/bridge-v2-assets-prompts.txt)：明确要求排除 AI moiré、虫状微纹理、密集条纹、编织纹、噪声网格、网点和颗粒。
- 两图都使用无损导入、`process/fix_alpha_border=true`、生成 mipmap，节点采用 `LinearWithMipmaps`。这是生成阶段的结构简化加运行时采样处理，未对图片做会损坏线条的强模糊处理。
- 已目视检查生成图、1280×720 实机关键帧和录像连续帧，未见明显摩尔纹、密集杂纹或重复网格闪烁。该结论仅覆盖本轮素材及显示尺寸，不声称所有分辨率和显示器都已验证。

第一轮实机发现左侧塔面下缘仍有裁切痕迹，随后为左右塔分别调整羽化终点，再完成最终两版复测。首轮证据保留在 `artifacts/bridge-v2/beta-before-edge-fade/`。

## 双版本定向结果

正式版 v0.107.1、测试版 v0.111.0 均使用独立开发环境、普通速度、Karen 存档继续进入瀑布巨兽战斗。以下项目两版均通过：

- 普通 X＝2：一次桥体，实际按防御→打击→防御依序自动打出三张，约定牌堆 3→0，三次出牌追光。
- 空牌源 X＝0：一次短点亮，无自动出牌与单张追光，无完整布景。
- 升级 X＝0：实际自动打出两张，第三张防御仍留在约定牌堆，追光数为 2。
- 空虚 X＝2：抽牌堆两张、弃牌堆一张，经原生洗牌依次打出三张；抽牌堆清空，一次来自抽牌堆的演出。
- 入场时切换战斗：旧特效节点清除，新战斗中没有旧自动出牌继续执行。
- 保存并目视核查移牌前后截图，动画收尾后执行 `karen_check_hand`；两版各六次检查均为手牌模型 5／可见节点 5，missing、unexpected、unexpectedPileIcons 均为空。
- 最终两版日志没有 `ERROR`、`Exception`、`SCRIPT ERROR` 或 `SHADER ERROR`。正式版仍记录原有瀑布巨兽音乐事件找不到的提示，未处理该原生音乐问题；新增音效和卡牌声已录入视频。

双版本构建成功，各版 23 条警告、0 错误；最终加载器构建 0 警告、0 错误。没有因这次美术修改扩展为完整测试。
