# 普通闪耀牌轻量回牌特效：2026-10-15

> 已撤回。用户随后澄清需要“卡牌上的常驻特效”，此处回牌实现属于误解，已移除对应节点、移动补丁和专项脚本。当前实现见 [普通闪耀卡牌常驻微光](shine-ambient-2026-10-15.md)。下文仅保留撤回前的设计和验证历史，旧录像不作为当前演出。

按“参照耗尽进入耗尽牌堆的特效，为普通闪耀牌增加更弱特效”的反馈，为本次打出后仍有闪耀、回到弃牌堆或普通抽牌堆的本地卡牌增加轻量收尾。沿用耗尽的金白星屑、收拢与加速语言，实际落到目标牌堆图标；不改变模型去向和闪耀消耗。

## 强度与节奏

| 星点半径 | 7，峰值 alpha 0.46 | 17，峰值 alpha 1 |
| 尾迹保留 | 0.10 秒，细双层线 | 0.16 秒，多层亮尾迹及散射星屑 |

| 速度曲线 | 45% 耗尽路程曲线＋55% 线性路程，理论峰值约平均速度 1.97 倍 | 完整缓起／急加速／减速吸入，约 3.15 倍 |

普通回牌曲线为浅上弧，终点实时读取实际图标。继续用弧长表控制行进；普通手牌不增加临界预告。最后一点闪耀、第二幕强制耗尽沿用完整耗尽演出；Instant 保留原生退场，燃料保留已有爆散／消耗，约定牌堆与空虚塔入口继续由原特效处理。

## 接线与视觉所有权

`ShineVfx` 在原生 `MoveCardNodeToNewPileBeforeTween` 重设父节点之前，记录真实来源是否为 PlayContainer。`NCardFlyVfx._Ready` 只接管带有本次来源记录、仍有闪耀且不应耗尽的局部回牌动画；该记录单次消费，随卡牌回池清空。模型移动仍完全由原生 `CardPileCmd` 执行。

首轮使用 `NCard.DisplayingPile == Play` 作为判据，没有触发新特效。只读观察确认：真实从打出区返回的节点此时仍可能保留 `Hand` 显示标记。最终改用实际源容器判据，并通过回合弃牌对照排除误触发。初轮和诊断记录分别保留在证据目录的 `first-attempt/`、`diagnostic-attempt/`。

`NKarenShineReturnVfx` 保留原生 `SwooshAwayCompletion`，只调用一次到达通知并回收视觉节点。中途换房间、目标失效或卡牌被其他命令接管时结束自身并完成等待；不释放已被其他父节点／模型占用的卡牌。收尾恢复卡牌的可见性、颜色及比例，避免污染对象池。
