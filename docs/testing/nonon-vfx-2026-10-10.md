# NONNON 扬剑破势特效定向验证

## 改动

- 采用 HTML 方案 E，移除来袭箭矢：冷白扬剑、剑柄局部红闪、一道覆盖敌方的弧形横扫，以及全战场随机灰蓝碎片。
- `KarenNonon` 通过原生 `AttackCommand.WithAttackerFx` 创建 `NKarenNononVfx`，替换旧版逐敌人巨型横斩。
- 普通模式在 0.66 秒命中，节点生命周期 2.35 秒（粒子强化后）；快速模式与原生命中等待统一缩放为 70%。Instant / NonInteractive 跳过绘制。
- 角色位置、缩放与敌人范围取自当前战斗节点。伤害、临时力量降低、闪耀递减仍由原有卡牌流程处理；数值不变。
- 修复实测发现的微小星芒三角化失败：半径缩到亚像素尺寸后停止绘制。

## 范围

按用户要求，不执行全面测试。仅构建双版本，并在各自隔离的单人环境选择 Karen 开局，使用 MCP 进入 `CULTISTS_NORMAL`，连续打出普通和升级 NONNON。开发命令仅用于准备两张卡与能量。

游戏、用户数据、日志均位于此工作树 `artifacts/nonon-game/{stable,beta}`；端口分别为 17637、17638。没有部署到 Steam 或主工作区开发游戏目录。

## 粒子与闪光强化复测

根据用户反馈，再次检查卡面和战斗立绘，强化剑柄红光、绕身风流和飞散碎片，保留无来袭箭矢的方案。

- 红闪锚点修正为战斗立绘实际持剑手的位置；发光时段从 0.28–0.53 秒延长到 0.19–0.83 秒，增加白热核心、红色辉光和更长的横向光线。
- 每次出牌生成 1,000 枚基础粒子，加每目标 64 枚命中粒子；双目标合计 1,128 枚。包括卷动光尘、扬剑飞屑、横扫光屑、暖色火花、灰白/深灰碎片与闪烁星点，另有 12 道绕身风带。
- 粒子只使用局部视觉随机数，不消耗战局 RNG。光点和拖尾合批提交，复用缓冲数组；碎片单独使用普通透明混合以保留暗色轮廓。
- 双版本重新构建，均为 0 错误、24 个既有警告。再次单人实录普通和升级卡，确认每目标 12 / 16 伤害、-12 / -16 力量、每张闪耀 9 → 8；手牌检查均为模型 5 / 可见 5。
- 抽帧确认红闪清晰、粒子随扬剑与横扫运动，尾迹正常消失；无多边形三角化错误。正式版日志没有 ERROR；测试版启动阶段出现一次原生 `worker_thread_pool.cpp:418 Invalid Task ID`，在继续战局和本次出牌之前，出牌阶段无错误。未扩展调查启动问题。
- 正式版录像约 10.53 秒，实际采集 29.61 fps；测试版约 10.50 秒，实际采集 29.72 fps。均为 1280×720 / H.264 / AAC；连续画面检查无超过 1 秒的静帧。这是录像采集速率，不作为游戏帧率基准。
- 音频复核：正式版 mean -45.7 dB / peak -22.2 dB；测试版 mean -43.2 dB / peak -20.1 dB。测试版第一遍近静音，重新应用取消静音后重录，交付第二遍。

强化版录像：`artifacts/nonon-vfx-review/stable-particles.mp4`、`artifacts/nonon-vfx-review/beta-particles.mp4`。对应 `*-particles-{before,normal,upgraded}.json`、前后截图、手牌检查与录像元数据保存在同目录。旧版录像保留供比较。仍未运行全面测试。

## 全场灰蓝风场与颜色校正

用户指出粒子颜色和范围不对，并明确选择“灰蓝风场覆盖整个战场”。此轮以该范围为准，不采用局限角色周身的方向。

- 灰蓝尘埃、风丝、深灰/浅灰碎片改用普通透明混合，避免叠加发光后变成纯白亮片。仅少量冷色星点使用叠加发光；移除大面积暖色火花。
- 根据当前视口计算整个战斗区域，避开顶栏和手牌；全场分布细尘、碎片及七道宽灰白风带，并加入边缘渐隐的灰蓝薄雾。粒子在区域边缘淡出，运动阻尼避免全部堆到右侧。
- 基础粒子仍为 1,000 枚（400 细尘、280 扬剑微屑、180 全场风带飞屑、20 剑柄红尘、120 碎片），命中粒子减为每目标 20 枚。双目标合计 1,040 枚，仅约 20 枚为发光星点。
- 红闪保留 0.19–0.83 秒的可读时长，白色光核缩小、红色辉光和横向光线收束，减少对角色轮廓的遮盖。命中时机、卡牌数值及 2.35 秒总时长不变。
- 双版本构建均为 0 错误、24 个既有警告。普通/升级卡再次定向实测：每目标 12 / 16 伤害、力量 0 → -12 → -28，两张卡各自闪耀 9 → 8；手牌模型与可见节点均为 5，无缺失或多余节点。
- 查看两版实际出牌截图与连续抽帧，确认灰蓝风场跨越整个战场，深浅碎片不再呈纯白，角色和手牌可辨。此次两版日志均无 ERROR / Exception / triangulation 错误。
- 两版视频均为约 10.5 秒、1280×720 / H.264 / AAC，先普通后升级。正式版实际采集 29.82 fps、测试版 29.52 fps；freezedetect 无超过 1 秒静帧。音频正式版 mean -45.2 dB / peak -21.3 dB，测试版 mean -46.0 dB / peak -22.2 dB。

最新视频为 `artifacts/nonon-vfx-review/stable-field.mp4` 与 `artifacts/nonon-vfx-review/beta-field.mp4`，状态、前后截图和手牌检查为同目录的 `*-field-*`。仍仅做本卡定向验证，未运行全面测试。

## 散落碎片随机性修订

用户指出场景中的大量碎片过于规整。本轮保留全战场灰蓝配色，将散落碎片改为主要表现。

- 移除七道平行风带、起手与横扫的重复风丝，保留主要扬剑与横扫剑光。底层薄雾改为位置、大小、出现时间和漂移各异的轻淡雾团。
- 每次出牌重新创建局部视觉随机数源，不消耗战局 RNG。随机选择 6–10 个疏密中心，混合局部聚集和全场散布，形成不均匀密度与自然空隙。
- 每次包含 460 枚细尘/少量冷光、660 枚不规则碎片、120 枚扬剑飞屑、18 枚局部红尘，另加每目标 22 枚命中粒子；双目标合计 1,302 枚，随各自出生和消退时间交错显示。
- 碎片分别随机生成五角轮廓、大小、长宽比、深浅、透明度、初始方向、速度、阻尼、扰动频率、旋转及翻面速度。小碎屑为主，穿插少量大块近景碎片，避免同尺寸、同方向、同节奏的排列。
- 两版构建均为 0 错误、24 个既有警告。定向实录普通与升级卡：伤害分别为 12 / 16，力量 0 → -12 → -28，两张卡各自闪耀 9 → 8；手牌模型和可见节点均为 5，无缺失或多余节点。
- 已查看操作前后截图、两次出牌的关键帧，确认碎片分布不同、独立翻转漂移，效果结束后正常消退。正式版日志无 ERROR；测试版在主菜单 Common 资源预加载时出现一次原生 `worker_thread_pool.cpp:418 Invalid Task ID`，在继续战局之前。出牌阶段没有错误或多边形三角化失败；未扩展调查启动问题。
- 两版录像均为 10.5 秒、1280×720 / H.264 / AAC，含游戏进程音频；正式版实际采集 29.38 fps、测试版 28.86 fps，均无超过 1 秒静帧。正式版音频 mean -45.2 dB / peak -22.9 dB；测试版 mean -45.9 dB / peak -21.5 dB。

最新实录为 `artifacts/nonon-vfx-review/stable-scatter.mp4`、`artifacts/nonon-vfx-review/beta-scatter.mp4`。对应 `*-scatter-*` 保存状态、前后截图、手牌检查、录像元数据与关键帧。仍未运行全面测试。

## 先斩击、后碎片的时序修正

用户指出碎片应由攻击带起，不能先于攻击铺满场景。

- 将横扫起始与展开时长共用为 0.53 秒、0.20 秒，剑风完成展开后再等待 0.06 秒，灰蓝碎片最早在 0.79 秒开始出现。伤害仍在 0.66 秒结算。
- 场景细尘、碎片和雾团根据距实际横斩曲线的距离增加延迟，再叠加少量随机时差，形成斩线附近先起、远处随后扩散的余波。全场随机疏密、形状、翻转和漂移继续保留。
- 原起手扬剑飞屑移至横斩余迹，命中碎片同样延后。起手仅保留剑光、剑柄红闪及其少量局部红尘；总生命周期仍为 2.35 秒。
- 双版本重新构建并各实录普通、升级各一次。逐阶段查看扬剑、命中、余波截图，确认起手与初次命中阶段没有灰蓝场景碎片，随后才出现全场散落碎片，结束后正常消退。
- 普通/升级伤害 12 / 16、力量 0 → -12 → -28、每张闪耀 9 → 8 均通过；操作前后截图已查看，手牌模型与可见节点均为 5。两版构建 0 错误、24 个既有警告，本轮两版日志均无 ERROR / Exception / triangulation 错误。
- 正式版实录 10.60 秒、实际采集 29.42 fps，测试版 10.57 秒、29.52 fps；均为 1280×720 / H.264 / AAC，freezedetect 无超过 1 秒静帧。游戏音频正式版 mean -45.1 dB / peak -21.7 dB，测试版 mean -46.0 dB / peak -21.4 dB。

最新视频：`artifacts/nonon-vfx-review/stable-wake.mp4`、`artifacts/nonon-vfx-review/beta-wake.mp4`；相应状态、手牌检查、前后截图及关键帧保存为 `*-wake-*`、`wake-*`。本轮仍仅做本卡定向验证，未运行全面测试。

## 细碎屑分层与剑光扰动

用户进一步区分细碎屑和大片碎片：允许部分细碎屑在起手时存在，攻击后增加数量，两类都应受到剑光扰动。

- 460 枚细尘中，160 枚从起手时便以低速漂浮，另 300 枚随斩击余波加入；120 枚短飞屑继续跟随横斩。660 枚不规则碎片与命中碎片仍在斩击后出现。双目标总量仍为 1,302 枚。
- 对扬剑、横扫两道实际剑光分别采样位置、切线与经过时间；时间使用与剑光展开相同的缓动曲线。邻近粒子在剑光经过时获得沿斩线和向外的速度扰动，并产生短暂卷动，随后受阻尼逐渐减速。
- 扰动随距离和余波时间衰减，并保留个体随机差异。细碎屑受力更明显，大片碎片反应较沉，同时改变旋转与翻面；不再只依靠与剑光无关的随机漂移。剑柄局部红尘独立保留。
- 双版本构建均为 0 错误、24 个既有警告。实际查看起手、剑光经过和碎片散开阶段，以及操作前后截图；普通/升级伤害 12 / 16、力量 0 → -12 → -28、两张卡各自闪耀 9 → 8 均正常，手牌模型与可见节点均为 5。本轮最终两版日志无 ERROR / Exception / triangulation 错误。
- 正式版最终录像 10.60 秒、实际采集 29.33 fps；测试版 10.53 秒、29.34 fps，均为 1280×720 / H.264 / AAC。正式版一遍采集在碎片阶段停顿约 1 秒，已重新录制；最终录像仅在悬停卡牌的静态阶段检出短静帧，特效阶段连续。
- 最终游戏音频：正式版 mean -45.2 dB / peak -21.0 dB，测试版 mean -46.1 dB / peak -22.2 dB。另从原录像截取第一张牌的完整特效，生成 0.5 倍速片段方便观察扰动，慢动作文件名包含 `slow`。

最新实录为 `artifacts/nonon-vfx-review/stable-gust.mp4`、`artifacts/nonon-vfx-review/beta-gust.mp4`；慢动作为 `stable-gust-slow.mp4`、`beta-gust-slow.mp4`。状态、截图、手牌核查和录像元数据在同目录的 `*-gust-*` 中。仍未运行全面测试。
