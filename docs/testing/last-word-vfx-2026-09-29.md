# 最后的台词：归属与收尾优化

基线：`9f6dc0494cd8084ae8553fc9817e7c47c906f687`。工作分支：`codex/last-word-vfx`。本轮只处理这张卡，等待用户查看实机后确认。

## 保留与修改

- 保留现有 OGV、T 字纹理、颜色、密度、运动、音效及正常出牌的等待和伤害规则；不重新导出影片。
- 文字与视频入口显式传入 `Owner`，文字来源通过对应玩家的生物节点确定，替代“第一个玩家”。从人物画布变换转到特效画布，避免混用全局位置与局部偏移。
- 两类节点保存创建时的战斗房间。房间失效、离场、换房间或战斗不再进行时隐藏并回收；视频退出树时停止播放器并解除 Finished 回调。影片正常淡出时原有文字分离逻辑保留。
- Instant 和非交互流程跳过长演出及其音效/BGM 停止操作，与 `Cmd.Wait` 的跳过语义一致，继续原有伤害执行。
- 视频资源不存在时先返回 fallback，避免直接加载缺失路径。
