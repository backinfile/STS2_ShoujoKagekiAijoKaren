# 空虚模式：约定塔退场与抽牌堆图标接替

基于 `main` 的 `87ae094`，任务分支为 `codex/void-tower-hide-20261012`。本次修改让《世界上最空虚的人》完成库存转换后，Karen 身后的塔、塔灯、塔火焰及点击区域退场，空虚模式的表现集中到抽牌堆图标。随后按玩家反馈调整退场时机，并恢复换用贴图塔时遗漏的塔脚传光、星光汇聚重组图标。

## 最终表现与实现

- 向下扫描及其光尾于激活后的 0.98 秒结束，此前塔保持完整。塔随后用 0.24 秒平滑淡出，1.22 秒完全隐藏，接上图标库存星光的展开。约定牌堆有牌、无牌使用相同顺序。不会关闭库存节点本身，图标上的星星、移牌尾迹及库存更新继续运行。
- 两道暖白光在扫描到塔脚时沿曲线传向抽牌堆图标，24 颗短暂星光汇聚到图标表面。传光和重组画在图标的独立前层，使用实际贴图塔脚与图标的画布坐标，不乘塔的淡出透明度；塔退场后仍完成收尾。无牌也播放，临时星光不进入逐张对应卡牌的库存集合。
- 卡牌对应的库存星星由下扫灯光从原位置带到塔脚，再随两道传光进入图标。库存星星与光束共用画布路径和起始时刻，以最多 0.075 秒的间隔跟随光头，到达后才汇入重组并展开环绕；不再保留提前从塔直接飞向图标的曲线。
- 空虚模式下的拖牌提示与《约定之塔》取牌蓄光改画在图标周围，不再点亮原塔的支架和平台。
- 已有燃烧的塔火焰与烟雾随塔淡出，图标火焰继续运行；空虚后再打出《燃烧吧燃烧吧》也不会预热原塔火焰。
- 隐藏后的塔轮廓不再接收点击。已经处于空虚状态时重建表现节点，塔直接保持隐藏；下一场普通战斗重新显示塔。
- 可见性查询只读取已有节点，防止粒子收尾期间因查询而重新创建已清理的塔。

涉及 `NKarenPromiseStarNode` 的 Void、Recall、Interaction、VoidOrbit 绘制分支，`NKarenBurnVfx` 和 `KarenPromiseVfxStarManager`。卡牌规则、移牌命令和共享入口坐标保持原有实现。

## 缺失特效的原因与回归检查

Git 历史中，`f0f5c81` 的 `DrawVoidProjection` 包含塔脚光束与 24 颗图标重组星光；`67dd794` 换用贴图塔时删掉了这个绘制分支。只调整塔透明度的 `3277e3e` 没有恢复它，真实库存星星的移动也不能替代无牌时的重组效果。随后 `7c1fd46` 将这个分支恢复到图标绘制层，并改用贴图塔脚坐标。

对 `3277e3e` 的无牌原始录像执行像素检查，光束区域为 0 帧、重组区域为 0 帧，检查失败。最新版本两版有牌／无牌的光束区域均至少 3 帧出现暖白光，重组区域分别为正式版 6／8 帧、测试版 7／7 帧；四段均通过。区域排除了能量数字、图标本体和数量标记；同时查看完整连续帧确认两道传光、星光汇聚与塔退场相接。固定区域检查的适用范围见录制工具说明。

玩家随后要求卡牌星星跟随传光。`7c1fd46` 中星星自激活后 0.1 秒独立飞往图标，而塔脚光束从 0.72 秒才开始；本轮删除这段提前飞行，将下扫收集、光束传递、图标环绕串联。逐帧检查同时核对位置与亮度：有牌时每版取得 42 个卡牌星星样本，距对应光束的最大误差约 0.022 像素，均未超过光头；0.14～0.69 秒没有提前抵达图标。无牌时整段真实库存星星为零。
