# 世界上最空虚的人：整塔传播与常驻塔影

2026-09-29。工作树 codex/void-activation-design，基于 main / 099ed2e。按用户确认的SVG实现。

## 实现

- 保留原生抽牌堆消耗表现。卡牌首次开启空虚时通知塔节点；视觉不增加玩法等待，不修改移牌或能力结算。
- 0.18～0.73秒暖白亮带自塔尖扫过所有红色结构线，包括斜撑、横梁和双腿；扫描对线段细分着色，不使用实体填充。
- 扫过后留下向右偏8设计单位的淡金轮廓，仅含塔尖、外侧两腿和两层横梁。亮度在0.34～0.52间按3秒周期变化，数字、星星和内部斜撑不复制。
- 0.72～1.01秒双塔脚向真实抽牌堆位置传光，随后在原牌堆图标旁画收拢轮廓与短亮；真实图标、数量、点击区域均保留，不创建额外卡牌节点。约1.43秒收净。已有塔星同拍短亮。
- 连接两端转换到视口坐标，HUD不受人物变形影响。非本地玩家只显示其角色塔动画，不连到本地牌堆。战斗结束由原有ClearAll清理，包括转换标记和计时。
- 原能力移牌钩子可能包含异步效果，转换期间提前保留正在显形的塔影；权威Sync完成后解除转换标记，避免能力尚未落地时塔影断掉。
- 只保留原有游戏声音，无新增音源。

## 初次检查修正与视觉取舍

最初固定等待1.3秒检查，遇到过去与未来逐张力量反馈时仍在结算，出现模型暂存出牌而可见节点已移走的中间态。该批证据没有视为通过；最终脚本等待空虚模式实际生效及4张牌到手，再等动画稳定检查。修复同时让塔影在异步转换期间持续存在。

过去与未来在空虚转换真实卡牌时仍会按原有钩子获得力量、播放连续时间环和绿色提示；初次开启的局部画面较密集。本轮保留该玩法与演出行为，没有修改其触发规则。常驻阶段时间环退场后，金色塔影与红塔、火焰可区分；无限时塔顶仍只显示∞◇。

首轮录像复制遇到Python访问输出路径失败，改为PowerShell Copy-Item保存MCP返回的已完成视频；游戏操作未因此失败。最终记录与初次记录目录分开保留。
