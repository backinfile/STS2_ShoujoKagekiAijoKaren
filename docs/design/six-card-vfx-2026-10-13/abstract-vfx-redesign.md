# 七张卡牌：抽象纹理与运动重设计

2026-10-13。用户指出储君 Mod 的特效图像以抽象图形为主。本轮替代 `2f8f957` 中的蛋糕、热锅、餐碗、纸票、检票章、牵手和奖励信封表现。

## 重新核对参考

已重新直接查看本地 Regent FX `c3ba1eb` 的原始 PNG：

- `alignment/fn0016.png`：连通的星芒亮核、长短尖刺、宽光晕。
- `glow/glow0016.png`：切面星芒、明暗阶层、短碎片，主体不是一个实物。
- `resonance/WXHX_resonance_sheet0020.png`：不规则多层能量波，内部有破口和层次。
- `spectrum_shift/f0025.png`：光谱拖尾、亮核和放射线。
- `common_glow_speck.png`：低复杂度光斑用于辅助，不能代替主动画。

同时核对了 Alignment、Resonance 的脚本及 Resonance 场景。主序列的内部形状随帧变化，脚本组织挂载、前后层、节奏和清理。需要借鉴的是这种有内部结构的抽象主体，而不是把实物图移动、放大、淡出，也不是用几根同样的线代替每张牌。

原有六牌设计文档已经明确要求不画纸票、印章、双手描边，上一轮偏离了这个约束。卡牌关联应由材质感、运动方向、节奏以及实际结果表达；不把“有关联”理解成照搬卡面物件。

## 本轮动作

| 卡牌 | 抽象主体 | 区分点 |
| --- | --- | --- |
| 蛋糕 | 金棕粗细碎屑、破碎的聚合流 | 松散到内收，收成一点后交接唯一的真实药水 |
| 什锦 | 浅琥珀暖汽、快速向上的体积流 | 快升、短确认、向两侧散热 |
| 晚餐 | 蜂蜜金的厚重暖辉与缓升金屑 | 慢起、三拍渐强、内收后温和退场 |
| 门票 | 珍珠白光瓣、淡蓝亮核与细粒子 | 根据卡图和能力图标轻收、舒展后消散；回合触发接续真实塔牌 |
| 两人的梦想 | 暖冷两股有体积的能量流 | 两源同拍汇合成奶白亮核，再交接真实光辉与约定星 |
| 一起闪耀吧 | 逐人落在脚下的舞台聚光束与光斑 | 队伍同拍点亮、每位真实受益者短确认，共享退场 |
| 光辉 | 实际卡面上的蓝白亮核与星芒 | 从卡面发射 2／4 火花进入实际能量槽，发射前保持真实卡牌可见 |

什锦在约定中变为晚餐，只在原生 Transform 附近使用收拢与散开的短碎屑，不播放角色获得力量的主体。

## 实现

`karen_benefit_flow.gdshader` 是原创程序化材质，使用分层噪声、局部密度、断裂遮罩和时间包络形成七种不同主体。前后两层共享单次施放参数；低频体积在角色后，少量高亮细节在前。现有原版 smoke、ash、sparkle 纹理补充微粒和余韵。

这次没有复制储君的 PNG、Shader 或音频，也没有把它的帧动画制作方式描述成我们的实现方式。当前实现是实时程序化形变，不是导出的 PNG 序列。

沿用已经接好的真实力量、药水、CardModel、Player 与能量观察；Instant、取消、退出战斗的清理保持独立于玩法结算。视觉验收优先检查主体可辨识、内部形变、前后层和节拍，不能仅凭编译与数值测试宣称美术通过。
