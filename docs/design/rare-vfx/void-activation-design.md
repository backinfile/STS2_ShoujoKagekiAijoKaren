# 世界上最空虚的人：开启动画补强

2026-09-29，基于 main / 099ed2e。本轮只设计 SVG 预览，不修改游戏代码。

## 原因与方向

KarenVoid 目前只在左下播放一次原生消耗表现，等待0.15秒后静默移除旧抽牌堆；约定牌堆转为 Draw 时 skipVisuals=true，保留塔星。因此此前整堆拖尾被取消后，模式开启缺少一段能看见的建立过程。

保留之前验证有效的经验：明显的亮点与分层拖尾、同一星星连续运动、数量准确、无限不显示数量、只做短暂关系提示。用现有塔脚、四芒星、卡背和原生消耗烟组合。不是TV镜头复刻，没有引入新的法阵或永久连线。

## 推荐时序

- 0–0.22秒：旧抽牌堆消散，短烟与余烬留在左下；整副牌只播一次。SVG烟是原生消耗表现的示意。
- 0.19–0.62秒：两侧塔脚点亮，各一道暖白拖尾沿低位弧线向左下汇合。这是建立映射的光，塔星不飞走。
- 0.53–0.89秒：抽牌堆两层错位卡背轮廓向中间收拢，新的约定卡背显形。轮廓是残影，不新增真实卡牌。
- 0.58–1.13秒：牌堆与已有塔星同步亮起一次；短连接收净，进入当前常驻表现。

再生产单独补牌仍向上走灯、横梁出星；空虚只在首次开启时向左下建立映射，两个动作方向和目的明确区分。

## 边界和落地原则

- 普通：塔5→5◇，抽牌堆示例7→0→5。塔星的位置和相位不重置。
- 已有再生产：塔∞→∞◇，实际抽牌堆最终10；不播放额外生成星星动画，不重新执行补牌。
- 约定牌堆为空：塔0→0◇，原抽牌堆消散，映射仍建立；不生成假星。空牌堆仍保留可交互图标。
- 原抽牌堆已空：跳过消耗段，不创造余烬；传光直接开始。
- 已有空虚时再次打出：保留当前无操作逻辑，不重复播放开启演出。
- 普通抽取和放入保持现有原生移牌，只在映射建立时播这套演出。
- 游戏计数读取真实模型；SVG的0.68秒计数跳变只为说明状态交接，不作为实际等待或结算约束。
- 接入时塔端用owner对应VFX坐标，抽牌堆端用本地UI真实位置；没有本地牌堆UI的玩家不向本地抽牌堆画连线。战斗结束/节点失效立即清理。只播一次，不逐张执行。
- 性能预算：两条短轨迹、最多两层残影、一次原生消耗，复用现有四芒星；不加全屏shader、长驻光束或新粒子纹理。
- 音效方案：沿用消耗声音，传光结束可配现有短闪耀声一次；需接入阶段先核对可用音源，预览无音频。

## 预览

void-activation-preview.html 为自包含SVG动态设计稿，保留既有人物素材。支持重播、暂停、拖动、四个关键帧、0.4倍慢放及普通/无限/空塔三种情形。默认停在显形帧，避免自动循环。实际游戏中的卡背、角色尺度和牌堆位置以游戏为准。尚未进行游戏构建或实机录制，设计确认后再接入。

浏览器验证：已查看传光中间帧、无限模式显形帧、空塔显形帧，并操作重播、模式切换和关键帧控件。无限标签无数量，空塔无驻留星。设计检测器无发现。常驻底图与手牌为位置参照，没有游戏实测结论。

## 反馈修订：整塔自上而下传播

用户认为塔脚传光范围太少，已将该段扩展为全塔传播，替代前述只从塔脚起光的时序：

- 0.18–0.73秒：塔尖先亮，约120设计单位宽的暖白亮带自上而下扫过全部骨架、斜撑、两层横梁与两侧塔腿。使用原塔线条的三层亮度蒙版，保持透空结构；光带后的亮度迅速回落，塔顶文字不跟随闪烁。
- 0.72–1.01秒：光到塔脚后衔接原有低位曲线，向左下抽牌堆汇合。
- 0.91–1.43秒：牌堆残影收拢显形，已有塔星同步短亮，连接收净。全程约1.4秒。

普通、无限、空塔三种情形共用整塔传播；不新增或搬走塔星。时间轴关键帧更名“整塔下传”，默认停在0.45秒展示横梁传播；已在浏览器查看0.45秒和0.68秒，确认横梁、斜撑及双腿都被依次照亮。仍仅更新SVG设计稿，没有游戏代码变化。设计检测器无发现。

## 常驻方案预览：双层塔影

开启下扫光会逐段留下淡金白色的第二层塔影。只描外侧两条塔腿、塔尖和两层横梁，不复制内部斜撑、数字和星星。塔影在红塔与人物之后，水平右偏可选4/8/14设计像素，并有关闭对照；默认8。亮度以3秒周期在0.34～0.52之间平缓变化，不消失、不闪烁。原塔位置、驻留星轨道不变。

预览时间轴延长到6秒，开启仍约1.4秒，后段用于查看常驻呼吸，默认停在1.8秒。暂停或拖动时呼吸也暂停；播放到末尾停止，不自动无限循环。已查看8像素常驻帧与14像素下扫中间帧，确认第二层轮廓逐段保留、数字与星星未复制，设计检测器无发现。此轮仅SVG，未新增抽放牌反馈或游戏代码。

## 补充：可见的原牌库摧毁与完整录像

原实现只在隐藏卡牌节点上播放消耗粒子，且额外减去半张牌的尺寸，导致焦点靠近屏幕边缘。现在从真实抽牌堆位置展开最多5张可见卡牌作为整叠牌库的视觉代表，0.28秒展开、短暂停留后灰化缩小消散；仅播放一次原版消耗粒子与声音。约0.65秒后继续整塔传光及常驻塔影。使用视觉副本，不逐张调用消耗命令，不改变原牌库直接移出战斗的语义。

原抽牌堆为空时跳过摧毁段；重复空虚仍不重播。本地HUD演出只对本地玩家播放；最多5个临时卡牌节点，finally中清理。此次双版本22个定向场景已完成，未做完整矩阵或多人测试。完整4分钟实录将两版各11段串联，右上角烧录版本、能力组合及段落说明，保留游戏进程音轨。见验证记录中的完整录像链接。

## 图标摧毁修订

用户看不清上一版卡牌展开与原版烟尘，改为直接处理真实抽牌堆Icon的纹理，不展示任何待摧毁卡牌。0～0.35秒稍微放大、上提、闪白并灰化，0.35～1.1秒切成30片向屏幕内上方散开、缩小淡出；真实Icon暂时透明，计数和按钮交互保留。随后继续整塔下传，传光抵达时恢复由EnterMode切换后的约定图标。节点退出时恢复原始SelfModulate，避免残留透明状态。

这是对上一节卡牌展开方案的替换。仍使用一次原版消耗音效；移牌语义不变。最新单独实录约10秒，仅打出空虚，标注了图标摧毁、整塔传光、图标显现和常驻阶段，不混入其他能力或抽牌操作。

## 恢复原版消耗风格

用户否定方块碎散，因此移除自制切片、闪白、灰度shader与位移。改用当前游戏版本的原生消耗类处理图标纹理：正式版NExhaustVfx原生烟尘/灰烬及StsColors.exhaustGray的0.3秒褪色；测试版NCardExhaustVfx的原生烧蚀shader、曲线和粒子边缘。测试版Create只构建节点，必须显式执行PlayAnimation，这也是早期只Create时没有烧蚀演出的原因。

原生API需要NCard，使用一个仅承载原抽牌堆Icon纹理的临时载体；所有真实卡牌外观子节点在渲染前隐藏，画面不会显示卡名、卡图或具体卡面。保留原生粒子资源和参数，只按HUD图标尺寸缩放。消耗后保持图标空缺，约定之塔传光抵达时恢复新图标；计数与交互区域保持原逻辑。

## 星光重塑替代矩形框

删除抽牌堆显形时的两层矩形残影、矩形闪光及大中心星，替换为24颗小四角星，复用塔星DrawStar。白色为主、少量淡金，大小2.8～5.2视口像素；按0.028秒错峰出生，在0.28秒内由图标上方散点汇入图标表面，随后逐颗淡出。重塑尾段延长至塔动画1.75秒，接续真实图标显现。原版消耗、塔脚传光、常驻塔影和图标切换时机不变。粒子只用于表现，不创建卡牌或改动数量。

数量徽标补充：数字与红色底托现在随旧Icon淡出，在四角星重塑时与新Icon同时恢复。隐藏期间仍更新真实数量，节点退出会恢复原透明度。
