# 《命运的齿轮》特效重做计划

2026-10-08。对象：`KarenGeer` / `KarenGeerPower`。本文只定方向与边界，不含最终数值。

## 0. 前提与边界

- **main 分支当前没有任何齿轮特效代码。** `KarenGeerPower` 只有规则：回合开始抽牌后，按 `Amount` 次从约定牌堆选 1 张并自动打出。
- 旧实现在 `.claude/worktrees/gear-redesign`（`NKarenGearVfx.cs` + `KarenGearVfxManager.cs`），未合并、未提交。本次**不延用**，该 worktree 中的这三个文件建议删除。
- 只做表现层。不改动卡牌规则、数值、选牌流程、结算顺序与结果。
- 符合 `design-notes.md`「共用规则」：装置与动作产生独特性；大演出与触发分开；变形分层、装置不镜像；不与约定塔、最后的台词互相吞没；Normal/Fast/Instant 各有策略。

## 2. 设计主张：塔基机械选牌轮

把齿轮做成**舞台后台的换景机械**，装在约定塔的塔基侧，与塔形成「齿轮—齿条」的咬合关系。齿轮是这台机械的驱动件，塔是它驱动的东西。

### 2.1 形态

- 一个**带实体齿**的齿轮（12 齿），半径约为塔高的 0.22，描边为主、不填充。
- 中心有固定轴心；外缘内侧有 3 个等分的**卡槽缺口**。
- 齿轮旁有一枚固定的**棘爪（pawl）**，只在啮合时与齿面接触。
- 齿的轮廓是本卡唯一的**锯齿形剪影**——项目里没有任何其它元素有齿状边缘，靠轮廓即可识别。

### 2.2 状态与动作

| 状态 | 表现 |
| --- | --- |
| **常驻** | 低亮暗红描边；每约 2.2 秒单格微动一次（待机走时，棘爪轻抬） |
| **啮合** | 半圈 180° 转动，过冲 8° 后回正；棘爪连续跨越 6 齿；塔身结构随动微亮 |
| **等待选择** | 停在啮合角度，棘爪显式锁死在齿上。不加文字，用「停顿感」表达等待玩家 |
| **确认** | 补完剩余半圈；被选牌的光从塔的螺旋轨道脱离，落入卡槽缺口，随齿轮送到出牌位 |
| **退出** | 棘爪松开，齿轮缓停，整体亮度回落 |

### 2.3 如何避免暗示随机

- 卡槽在**确认前是空的**，不显示任何候选牌身份。
- **不出现指针**，不出现「转盘落定」的落点动画。
- 玩家在选牌界面上看到的就是真实候选牌；齿轮只表达「机械已经就位，等你决定」。

## 3. 位置、尺寸与层级

- **锚点**：塔局部设计空间的塔基左下（约 `(-105, 52)`），与塔的数量标注（主展望台左侧）错开。
- **计算方式**：不依赖塔节点是否已创建，自己按塔的同一规则取锚——`creature.VfxSpawnPosition` ＋ `Visuals.GlobalTransform` 的两个基向量长度。
- **缩放**：跟随人物绝对缩放；人物缩小/放大时齿轮同步，文字与 UI 不受影响。
- **镜像**：人物水平翻转时齿轮**不镜像**（与塔一致，否则齿向与棘爪会反向）。
- **层级**：`ShowBehindParent = true`，`ZIndex = 1`（塔为 0）。这样齿轮压在塔上、仍在角色身体之后，且不依赖在父节点中的插入顺序。

## 4. 时序（三档）

| 阶段 | Normal | Fast | Instant |
| --- | --- | --- | --- |
| 啮合 | 0.55s | 0.24s | 跳过 |
| 等待 | 不限，由玩家决定 | 同左 | 同左 |
| 确认 | 0.60s | 0.28s | 跳过 |
| 退出 | 0.45s | 0.20s | 跳过 |

## 5. 关键改动：特效不阻塞结算

这是相对旧实现最重要的一处设计修正。

- 删除两处 `Task.Delay`。
- **啮合动画 fire-and-forget**，与选牌界面同时开始——玩家的思考时间天然覆盖动画，不额外增加延迟。
- **确认动画 fire-and-forget**，在 `CardCmd.AutoPlay` 之后启动。
- `Amount > 1`：首次完整啮合；第 2..N 次只做单齿重扣（0.18s），**音效合并为一次**，不延长前摇。
- `Instant` / `NonInteractiveMode`：完全跳过演出，不影响结算时序（对齐 `KarenLastWord` 的写法）。

## 6. 虚空模式

虚空模式下约定牌堆重定向到抽牌堆，塔已切换轮廓与图标。齿轮需同步切换：

- 描边改用 `EchoGold #ffe6b6`，整体降饱和。
- 卡槽语义指向抽牌堆，不声称在操作约定牌堆。

## 7. 音效

- 需要 2 个新音效：`karen_gear_engage`（棘轮啮合，含 1–2 次咔嗒）、`karen_gear_lock`（止动确认）。
- 按项目约定：**最终音频文件由用户提供**，代码只负责接线、音量与降级（缺文件时静默，不报错）。
- 走 `KarenAudioManager.PlaySfx`，自动跟随游戏 SFX 音量；不循环；战斗结束时不留残余播放器。

## 8. 生命周期

- 管理器沿用项目模式：`SpireField<Player, Node>` 缓存 ＋ `Callable.From(...).CallDeferred()`。
- 创建：`KarenGeerPower.AfterApplied`。
- 销毁：`AfterRemoved`；并在战斗结束/角色死亡处兜底，与塔的 `ClearAll` 调用点保持一致。
- `_Process` 每帧校验 creature 节点有效性，失效即 `QueueFreeSafely`。

## 10. 验收

构建：stable 与 beta 双版本，0 错误。

实机（stable ＋ beta 各一次）：Karen 开局 → 打出《命运的齿轮》→ 向约定牌堆放入 3 张牌 → 结束回合，观察啮合、等待、选择、确认、退出五段。

检查项：

- [ ] 尺寸跟随：人物缩小/放大后齿轮同步，刻度与齿形不错位
- [ ] 翻转：人物朝左时齿轮不镜像，棘爪仍朝正确一侧
- [ ] 快速三档：Normal / Fast / Instant 行为符合第 4 节
- [ ] `Amount = 3`：三次触发中只有首次完整啮合，音效不叠加
- [ ] 虚空模式：描边与语义切换正确
- [ ] 战斗结束/角色死亡：无残留节点，无残留音效
- [ ] 不遮挡：血条、手牌、选牌目标与数量标注均不被压住
- [ ] 不阻塞：选牌界面出现时机与未装备本卡时一致

工具：KarenSTS2MCP 录制**有声**实机画面并保存截图；涉及移牌时执行只读命令 `karen_check_hand`；两份日志不得出现 ERROR/Exception。

交付后暂停，等待用户确认再继续下一项。

## 13. 第二版修改计划（2026-10-08，待确认）

用户反馈：①不需要表达张数/层数；②整体偏朴素；③先去掉音效。

### 去掉

- 3 个卡槽、`Amount>1` 的补转演出（多层时每轮都按同一套完整演出走，不做区分）。
- 两个临时音效文件、`KarenSfx` 常量与播放调用。

### 加强：从「一个零件」改成「一组舞台机械」

1. **双齿轮咬合**：大齿轮（主）＋右上小齿轮（从，约 0.45 倍），反向转动、齿位真实啮合。取代单个棘爪，机械感更强。
2. **刻度外环**：大齿轮外侧加一圈细刻度环，12 点方向固定一颗**星扣**，作为「命运指向」的唯一焦点。外环与齿轮反向慢转。
3. **入场（打出时一次性大演出，约 1.2 秒）**：齿从轮毂向外逐个展开 → 小齿轮滑入咬合 → 外环描边一圈 → 星扣点亮并闪一下。
4. **常驻**：连续极慢转动（不再逐齿顿挫），轮毂有微弱呼吸光；整体亮度保持低，不抢塔和人物。
5. **啮合（回合开始）**：两轮加速反转半圈，**齿位接触点迸出白色火花**；动力沿塔腿向上传导一道光（齿轮在驱动塔），星扣蓄光。
6. **确认（选中后）**：选中牌的光从塔中星位落到星扣 → 星扣爆闪 → 一道红白光带从齿轮向出牌区方向**射出**（把牌送上舞台）→ 外环扩散一圈冲击波后回到常驻。
7. **离场**：齿逐个收回轮毂后淡出。

### 不变

- 位置（塔基左侧、人物身后）、跟随缩放但不镜像、红 `#ff526a` / 白 `#fff5db` 配色、虚空模式改用金色。
- 回合开始在选牌界面打开前先演完啮合（正常 0.55 秒 / 快速 0.24 秒 / 瞬间跳过）。
- 不暗示随机：没有指针、没有转盘落点。

### 验证

双版本构建，正式版重录一段无声视频（入场 → 放牌 → 回合啮合 → 选择 → 确认），附关键帧截图。
