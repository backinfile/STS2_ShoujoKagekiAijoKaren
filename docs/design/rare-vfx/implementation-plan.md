## 执行约定

1. 每次只实现一个特效，保留卡牌规则、现有资源与可复用的播放管理器。
2. 做与该项有关的构建及定向实机检查，不跑完整测试矩阵。正式版与测试版分别注明结果；未测项明确记录。
3. 用 KarenSTS2MCP 录制真实游戏画面，只展示当前特效的正常触发，不录制缩小/翻转等其他情况；确认录像完成封装。默认开启游戏声音；无声录像明确标注，不用 HTML 代替实机录像。
4. 交付录像、改动说明和检查结果后立即暂停，请用户确认是否继续；收到确认前不实现下一项。用户要求调整时只迭代当前项。
5. 未获合并授权前保留独立 worktree；main 中原有未提交文件不动。
6. 2026-10-08 用户补充：MCP 操作时保持游戏最小化，避免抢占前台。
