## 重点重设计：过去与未来

**选用前后门景，完全放弃原有地面光环作为主体。** 光环只能表示“有一个 buff”，无法说明“过去的约定成为当下力量”。两个舞台门景让这种关系直接可见：后景冷蓝、低亮，前景暖白、打开，角色位于两段时间之间；抽牌光从塔穿过角色，再收至临时力量提示。

候选比较：逆转时钟虽直观但太接近一般时间魔法；双环会延续现有问题；第二座塔会与约定牌堆抢轮廓。前后门景使用不同于塔的矩形外形，能以较少图元说明进退关系，故作为当前推荐。

- 入场最多约 1.6 秒；预览展示完整 4.2 秒分镜，含触发与回到常驻。
- 常驻只保留低亮门框和星扣，不旋转、不持续发声。正式游戏建议可见高度约为角色的 1.15 倍；预览适度放大以便评审。
- 抽牌触发建议 0.55–0.8 秒；连抽合并光路，力量结算仍逐次由模型处理。预览时间是放慢后的观察节奏，不要求命令阻塞同样时长。
- 门景、塔和人物各自锚定。门景使用角色绝对尺寸，前后方向不被水平翻转颠倒；力量数字和文字始终正向。
- 每个 owner 独立实例；复用必须核验 owner，不能搜索同一父节点的任意同类型节点。

## 共用规则

1. **独特性来自装置与动作。** 可以复用线条材质、光束和卡牌节点，但不能仅修改配色就把同一动画用于 26 张牌。下列每张卡具有独立 SVG 场景分支。
2. **大演出与触发分开。** 持续能力入场一次，之后使用短触发；等待选择时静止，离开战斗时取消。不同事件使用独立入口，不能根据视觉猜测是否结算成功。
3. **变形分层。** 人物尺寸影响贴身装置与发射锚点；UI 字体、手牌、奖励与票券信息保持可读。翻转只作用人物朝向，塔、门景、字幕和 UI 不镜像。预览双人开关提供空间对照，不能证明游戏多人实例隔离已修复。
4. **避免大效果相互吞没。** 最后的台词是最高优先级；其次罪过灯阵/塔桥；常驻塔与门景降低亮度。常驻时不遮住角色脸、血条或选牌目标。
5. **多牌/多段预算。** 只显示有限窗口的卡牌轨迹，合并粒子与音效，但不合并或删掉实际结算。高次数不延长前摇；Normal/Fast/Instant 在实现时各有策略。
6. **音效只是草稿。** HTML 使用 Web Audio 合成 4 个节奏点，体现轻/重、先后与回声；没有原作人声、曲目或最终 Foley 资产。默认关闭，由用户勾选后启用。

### 01. 过去与未来 — 前后门景

[源码](../../../src/Core/Models/Cards/promisePile/KarenPastAndFuture.cs) · [播放分镜](preview.html#past)

**设计：** 用前后错位的舞台门景替换地面光环。过去是偏后、低亮的冷蓝景框；未来是向前打开的暖白门扉。角色站在两者之间，约定牌成为连接的光。

**顺序：** 入场：门景沿舞台轨道升起；常驻：只保留两道细线和星扣；抽出一张约定牌：光从塔经过后景、穿过角色、打开前景，再收至力量图标。

**分镜节奏：** 0.00 旧景定位 / 0.65 新景展开 / 1.55 光穿角色 / 2.20 临时力量确认 / 3.40 回到安静常驻。预览 4.2 秒。

**声音：** 低音拨弦回应一声清亮钟音；每次抽牌只播 0.3 秒双音，连续抽牌合为一句。

**约束：** 每个 owner 独立门景；宽高跟随绝对缩放，方向不镜像；峰值亮度只在抽牌时出现；不增加第二座塔。

**落地：** 可先替换 Ring 节点；保留模式逻辑，Pulse 接抽牌事件。预览以原作舞台/光路语汇进行原创转译，不声称复刻某个镜头。

**依据：** 剧场版宣发构图与主题转译。

### 02. 我们犯下的罪过 — 多轮审判灯

[源码](../../../src/Core/Models/Cards/shine/KarenCarryingGuilt.cs) · [播放分镜](preview.html#guilt)

**设计：** 沿用用户认可的多轮灯光和音效，让每轮照明像点名一份已耗尽的闪耀；最终所有光束在目标汇合。

**顺序：** 先落单灯；左右交替第二、第三轮；耗尽过的不同卡越多，灯位更密；最终白色窄光结算伤害。

**分镜节奏：** 0.00 黑场压低 / 0.35 单灯 / 0.95 双灯 / 1.65 交叉灯阵 / 2.45 终束命中 / 3.30 清场。预览 3.8 秒。

**声音：** 三个有间隔的灯具开关声，末轮低鼓和金属余响；不新增人声台词。

**约束：** 最多五轮视觉层级；数量再多只加密灯位，不延长总时长；灯束锁定目标，角色翻转不改灯光方向。

**落地：** 强化现有 StageLight；用游戏时间等待替换墙钟等待。预览显示三轮，不据此改变伤害公式。

**依据：** TV 舞台/约定主题（具体对应见来源笔记）。

### 03. 燃烧吧燃烧吧 — 焚纸炉膛

[源码](../../../src/Core/Models/Cards/neutral/KarenBurn.cs) · [播放分镜](preview.html#burn)

**设计：** 燃烧不是围着人物铺满火粒子：塔脚出现狭长炉口，卡牌经过后像舞台纸景一样被烧出金边。

**顺序：** 炉膛点火；抽牌通过热流后显出升级金边；牌角留焦痕提示本次打出将消耗；空闲只留低矮余烬。

**分镜节奏：** 0.00 炉口开启 / 0.55 燃料点火 / 1.30 卡牌淬边 / 2.15 升级亮边 / 2.90 余烬常驻。预览 3.5 秒。

**声音：** 短擦火声、纸边燃烧声、升级时一点金属亮音；无持续火焰底噪。

**约束：** 常驻限制在塔底，不覆盖血条；炉口随塔锚点，不把整个屏幕随人物缩放。

**落地：** 保留 Burn 模式规则；替换贴身随机粒子，新增牌角短效。原创炉口设计，借燃烧/再登台主题。

**依据：** 剧场版宣发构图与主题转译。

### 04. 觉醒形态 — 升降舞台

[源码](../../../src/Core/Models/Cards/neutral/KarenForm.cs) · [播放分镜](preview.html#form)

**设计：** 以舞台升降台和打开的翼幕替代全屏风线。人物被一块窄舞台托起，服装轮廓短暂描红。

**顺序：** 舞台台阶升起；两侧翼幕分开；中心人物重新被追光找到；每回合抽满手牌只重播一次台口开光。

**分镜节奏：** 0.00 台口描线 / 0.65 台阶升起 / 1.45 翼幕打开 / 2.35 全手牌展开 / 3.50 舞台归位。预览 4.2 秒。

**声音：** 舞台机械低鸣接一次向上扫弦；入场才切换既有 BGM，回合触发不重启音乐。

**约束：** 仅入场做大演出，持续只保留台口星记；Power 移除与恢复驱动状态。

**落地：** 区分本地屏幕 BGM 与所有人可见的角色升台；无需镜像文字或地面台阶。

**依据：** TV 舞台/约定主题（具体对应见来源笔记）。

### 05. 命运的齿轮 — 机械选牌轮

[源码](../../../src/Core/Models/Cards/neutral/KarenGeer.cs) · [播放分镜](preview.html#gear)

**设计：** 在塔侧挂一个有实体齿槽的舞台调度轮；一张牌被齿槽托到演出位置，像后台换景机械。

**顺序：** 齿轮咬合半圈；三个牌槽经过观察窗；选择的牌被卡榫推向出牌区，其他牌槽退回。

**分镜节奏：** 0.00 齿槽入位 / 0.55 啮合 / 1.30 选择窗定位 / 2.00 推牌 / 2.80 静止。预览 3.4 秒。

**声音：** 两次棘轮咔嗒加一次止动声；等待玩家选择时不循环发声。

**约束：** 旋转只发生于回合触发；常驻轮缘低亮、最多三个可见牌槽，不暗示随机选择。

**落地：** 接 KarenGeerPower 的选择结果；不能在选择完成前演出具体牌被打出。

**依据：** 原创装置；唯一原作镜头未确认。

### 06. 最后的台词 — 文字终幕

[源码](../../../src/Core/Models/Cards/neutral/KarenLastWord.cs) · [播放分镜](preview.html#last)

**设计：** 保留最后台词的高规格：窄银幕先收走其余舞台，几行抽象台词线聚成一条贯穿线，再由红色幕布落下。

**顺序：** 可打出时只保留牌框提示；实际打出才收束画幅、汇聚文字、贯穿所有敌人；视频版本沿用原素材，SVG 是节奏替身。

**分镜节奏：** 0.00 静默收幅 / 0.90 文字聚拢 / 2.20 一线贯穿 / 3.10 余响 / 4.35 落幕退出。预览 5.2 秒。

**声音：** 保留既有声音方案；预览用低音、长音和一道风切代替，不播放原曲或原对白。

**约束：** 正式实现同步视频结束与伤害关键帧；Instant 跳过大演出；发射源传入 owner。

**落地：** 全局终结优先级最高，暂压其他大特效；现有影片不需要被抽象 SVG 替换。

**依据：** 官方先导宣发贯穿主题。

### 07. 唤醒 — 呼唤声纹

[源码](../../../src/Core/Models/Cards/globalMove/KarenWakeUp.cs) · [播放分镜](preview.html#wake)

**设计：** 一条横向声纹从角色出发，抵达牌堆后竖起成两道细追光，把选择的牌带回手中。

**顺序：** 声纹扩展；选中牌像被叫到名字般抬头；两张牌沿声纹返回手牌区；未选牌继续暗着。

**分镜节奏：** 0.00 一次呼唤 / 0.60 声纹触牌 / 1.15 两牌起身 / 1.85 回手 / 2.45 消散。预览 2.8 秒。

**声音：** 轻呼吸式风声和两声不同音高的清音；不编造角色原声台词。

**约束：** 选牌完成才播；基础/升级来源分别用真实牌堆锚点；不遮挡选择界面。

**落地：** 原作对应关系仍属主题联想；玩法只取回选中的牌，不演成全牌堆复活。

**依据：** 剧场版宣发构图与主题转译。

### 08. Banana蛋糕 — 蛋糕与药瓶

[源码](../../../src/Core/Models/Cards/neutral/KarenBananaCake.cs) · [播放分镜](preview.html#cake)

**设计：** 用餐碟、切片和蒸汽表达日常温度：一块蛋糕旋入餐碟，奶油状蒸汽凝成肌肉药水瓶。

**顺序：** 餐碟划入；切片落盘；蒸汽卷成瓶形；瓶子飞到药水栏，餐碟退场。

**分镜节奏：** 0.00 餐碟 / 0.50 蛋糕 / 1.15 蒸汽成瓶 / 2.00 药水入栏 / 2.65 退出。预览 3.0 秒。
