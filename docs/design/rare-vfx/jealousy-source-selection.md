## 历史第一版时间线（已停用）

- 普通模式 0–0.42 秒：青绿弧光带薄金线从真实角色向真实敌人传播，星扣沿曲线移动；尾迹随距离变化。
- 实际命中回调：终止传播中的星扣，目标处播放约 0.56 秒的斜向青绿切光、金白短闪、圆形金属星扣和 18 个有限碎光。沿用原生斩击音效。
- `OnShineExhausted` 的原有奖励循环成功后：额外升起 1 / 2 颗星扣、双金线环与细碎光，表示已追加战后遗物奖励；复用项目已有短确认声音。
- Fast 时长乘 0.7；Instant 与 NonInteractive 不创建自定义节点。所有规则与奖励仍由原生命令决定。
- 完整画布变换定位；攻击随当前目标移动，奖励跟随所属玩家；节点归当前战斗，失去主人或换房间清理。无全屏滤镜、时间缩放和角色位移。
