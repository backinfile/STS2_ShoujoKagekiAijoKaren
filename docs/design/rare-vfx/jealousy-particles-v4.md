# 嫉妒第四版：机制与制作选择

## 机制

| 项目 | 实际代码与表现责任 |
| --- | --- |
| 类型／费用 | 1 费稀有攻击牌，指定单个敌人 |
| 普通／升级 | 单次伤害 15／20，交给原生 DamageCmd.Attack 结算 |
| 闪耀 | 初始上限 9；耗尽触发 OnShineExhausted，追加 1／2 份战后遗物奖励 |
| 持续状态 | 本牌不施加持续 Power，没有新增常驻主体 |
| 额外重播 | ExtraReplay 系统让 OnPlay 再次执行；每次真实执行有自己的起势、命中、粒子与清理 |
| 用户限制 | 角色不移动；闪耀耗尽奖励不配专属特效；方片参考 TV 真昼 |

源文件：`KarenJealousy.cs`、`KarenBaseCardModel.cs`、`ShinePileManager.cs`、`ExtraReplayPatch.cs`。奖励命令保留原行为，通用闪耀／原生 UI 与本牌独立。

## 真实事件与演出

| 时点 | 视觉与实现 |
| --- | --- |
| WithAttackerFx | 建立独立起势节点，读取当前角色与目标的完整画布变换；角色自带 Attack 位移动画继续停用 |
| 0.035–0.50 秒 | 加速推进的短攻击尖端；原生 CPUParticles2D 在运动发射器处发射方片尾迹，已发射粒子留在世界空间 |
| 原生真实命中回调 | 创建目标处短切光和白闪，启动 34 枚薄方片＋14 枚小星闪的原生单次粒子；重击音接到这里 |
| 命中后 | 方片沿前向扇形扩散、阻尼减速、少量下落；Shader 按各粒子寿命与旋转产生侧翻和面高光，约 0.72 秒结束 |
| 快速／瞬时 | Fast 的时钟和原生粒子 SpeedScale 同步为 1／0.7；Instant 和 NonInteractive 跳过自定义节点 |
| 中断／退场 | 起势失去主人或目标、战斗变更或结束时清理；正常寿命到期释放父节点及其粒子。中断前后不需要恢复角色变换 |

## 技术与预算

主体采用少量渐细线段与局部柔光，绘制函数只负责主形。装饰全部交给原生粒子，删除第三版逐枚方片与星闪的绘制循环。一个起势节点含 1 个、12 容量的尾迹发射器；一个命中节点含 2 个、34＋14 容量的单次发射器。粒子使用 32×32 共享白四边形，Shader 负责方形面、边缘、高光与小星形，材质、色带和物理参数均按次独立。

短切光和粒子属于局部实时效果，采用原生粒子与 Shader 足以随目标、距离和缩放变化；本轮无需增加固定透明帧序列。用户明确要求角色原位，因此不添加身体动作或残影。它是一击攻击，命中次数由真实原生命令决定；额外重播验证两个独立真实命中及粒子重叠时的材质隔离。
