## 已验证

使用本地 Microsoft Edge / Playwright 对最终 HTML 做针对性检查：

- 六张卡正常显示，嵌入素材可解码，没有 JavaScript 页面异常。
- 共 13 种组合：蛋糕成功/满栏；什锦与晚餐；门票与梦想首次施放/单层触发/三层触发（梦想包含空虚入口）；一起闪耀吧 2/3/4 人。
- 各组合结束帧的新增 Canvas 颗粒数量均为零。
- 播放、暂停、重播、一次播放结束、循环、时间轴、关键时点、阶段切换、层数及空虚开关通过。
- 1440 像素桌面与 390 像素移动布局没有横向溢出，已经目视六张代表帧与整页截图。
- 两份 MD 的本地链接、固定提交的源码路径、UTF-8 编码检查通过。
- 原版 25 张牌实际类型核对为 16 Attack、5 Skill、4 Power；frames 数量核对为 1128。

[机器检查记录](../../../artifacts/reference-mods/regentfx-analysis-2026-10-12/redesign-qa/checks.json)，[文档检查记录](../../../artifacts/reference-mods/regentfx-analysis-2026-10-12/document-checks.json)。

## 当前边界

本页为 Canvas 设计预演，没有运行游戏命令，没有构建或部署新的 Godot VFX。卡牌、药水、库存和奖励结果均为概念示意，尚未验证双版本实机、多人与 GPU 性能。

Banana 原 worktree 的专项通过记录属于此前实现；本次没有修改它的源码，也没有将其结果算作新方案验证。门票、梦想和一起闪耀吧原 worktree 的文件也保持原样。

页面图片全部内嵌，可以离线打开。素材哈希与来源预演路径见 [assets-provenance.json](assets-provenance.json)。现有 worktree 的截图仅作旧方向对照。
