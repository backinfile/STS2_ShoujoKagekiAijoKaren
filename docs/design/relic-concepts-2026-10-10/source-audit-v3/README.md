## 棒球猫

- 官方名称：スズダルキャット。
- 主参考：[武士道官方新闻稿中的鼠标垫图案](https://prtimes.jp/main/html/rd/p/000006806.000014827.html)。它能明确显示脸、黄色横椭圆眼睛与黑色竖向瞳孔、黑鼻子、粉色吐舌、露出的猫耳，以及带侧面护耳的红色棒球头盔。
- 辅助参考：[武士道官方毛绒商品](https://bushiroad-store.com/products/2000185923000)，用于核对身体和深蓝紫球衣上的红色 `SCC`。
- 当前稿的问题：把眼睛画成棕色方眼；鼻口画成小粉鼻加倒 V；没有吐舌；猫耳与头盔护耳缺失；字样画成 `COC`。这些是造型错误，不能只靠去纹理修复。
- 老 Mod 的原图仍可说明持球棒站姿，但128像素图不再单独承担面部细节参考。

## 星形发饰

- 主参考：[COSPA「ひかりの髪飾り」官方商品页面](https://www.geestore.com/detail/id/00000090566)，同页提供角色对照图、实物正反面与侧面。
- 正面可见一大一小两颗四角星相接并有重叠；背面可见发夹。实际商品有曲面、厚度和金属反光。
- 当前稿的问题：把卡图里的星形剪影直接做成两颗悬空的细长闪光符号，没有核对相接结构、比例和发夹的物体感。此前 Star_p.png 不再作为唯一的发饰参考。
- 实物照片用于核对结构；制作动画平涂图时，应保留动画配色并避免把商品摄影的强反光照搬成新增纹样。

## 星之王冠

- 参考：[TV 动画第11话截图的转载页面](https://anime-tip.com/sahplant/revuestarlight/9060)。原截图含 TBS 标志，本地文件为 `references/tiara-tv11.jpg`。这是真实动画画面，来源页面不是官方设定集。
- 截图可核对神乐光头上的星之冠：淡金色细冠架、卷曲镂空、纵向粉色椭圆宝石，以及顶部、两侧、底部的白色小装饰。
- 当前稿的问题：整体被压扁，冠架增厚；两侧和底部白色装饰缺失；卷曲及镂空比例改变。下一版应沿原截图轮廓提取、补边，不再扩展为通用珠宝冠冕。
- 不与爱城华恋的红色王冠发夹混用。
