以 Shiv 为主体：一枚贯刺，六层粒子

Shiv 的攻击辨识来自快速掠过的尖刃、目标处的小闪花、继续向前喷出的细火花。增加华丽程度，适合沿着这条方向补密度、速度差和碎光层次。

先看原生分工。切换“华丽化草案”查看更密的定向火花与次级碎光；图中形状和配色是结构示意。

它的漂亮，来自快慢和长短的分层

主刃速度 9000–12000，碎点速度有宽范围，并会按速度拉长。很少的初始粒子，也能给出飞行、穿透、破碎与烟尾。

华丽感集中在命中之后

保持一枚主刃和一次短闪花，加密朝前喷出的细线，再延后 30–60 ms 出现小亮片。用大小、速度、亮度区分层次。

两个阶段，短峰值与长清理分开

0 ms

节点开始：飞行刀芒、飞行碎点启动。

+150 ms

尖核、命中火花、闪花、薄烟启动，并触发一次弱震。

再等 2 s

清理整个节点。主形状与闪花早已快速收缩消退。

这是普通计时条件下的节点名义时序，Cmd.Wait 会随时间缩放或在 Instant 等条件下跳过。AttackCommand 不等待整个节点结束，内部 150 ms 不能直接当作 HP 扣除时刻。Silent 的专属 Shiv 动画另有 0.2 秒等待；Karen 当前普通攻击等待为 0.15 秒。

实际贴图，以及前一次分析的更正

当前 Shiv 使用 dagger_spray_single.png。之前展示的 shiv_simple.png 与 shiv_trail.png 出现在调试场景 Graveyard，不能作为活动 Shiv 主体的依据。

亮度有尖锐的内部层次

飞刃 LUT 最高设为 HDR (3,3,3)，命中尖核最高为 (12,8,8)。高亮核心与弱尾部形成反差，最终显示仍取决于渲染设置。

改 tint 不会统一所有颜色

原生只调色刀芒、尖核、命中火花和闪花。飞行碎点、薄烟另有材质；Karen 的红白金配色应逐层处理。

三种华丽化外观，动作都保持 Shiv

绯光贯刺 · 首推

暖红边、白亮尖核、少量金色细火花。短尖片从命中处向前喷出，最像华恋自身的迅速剑击。

再燃灯屑

主刃相同，次级碎光改成成对红白小亮点，错开闪出。转译再生产灯泡的色彩与闪耀。

双光贯刺

一枚主刃保留白亮尖端，拖尾边缘和碎光交替暖红、冷白。两色一起装饰同一次攻击。
