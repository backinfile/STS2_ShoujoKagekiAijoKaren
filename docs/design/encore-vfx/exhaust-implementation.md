# 《续演》专属消耗：绯光退场

2026-10-12。用户要求调整这张牌的消耗特效。效果从卡牌实际消耗位置开始：金色卡缘短闪、48 枚红金菱形光屑与 12 枚边缘星芒。余光约 0.9 秒内消退，与此前 Shiv 式绯光贯刺衔接。

## 接入与边界

- 正式版通过 NExhaustVfx.Create，测试版通过 NCardExhaustVfx.Create 的 Harmony 前后缀接入；只匹配 KarenContinue。
- Create 前记录卡牌 GlobalTransform，新增独立的 Node2D 以此放置；原生流程继续处理卡牌变灰／侵蚀、音效、移牌和对象池归还。
- 隐藏本次原生消耗实例的 GPU 灰烟等粒子，替换为红金光屑。递归时跳过整个 NCard 子树，避免改变卡牌对象池中的粒子可见性。
- 新粒子为加法混合的程序几何，不添加贴图，不修改卡牌材质、父子关系或规则等待。测试版卡面的原生紫色侵蚀边缘保留。
- 闪边约 0.18 秒；碎光分批生成并上升，单枚寿命 0.36–0.60 秒。Fast 按 1.6 倍播放；Instant、非交互与隐藏出牌容器条件保留原生路径。
- 伤害、消耗规则、原生卡牌清理责任保持原有接线。其他卡的消耗不应用此特效。
