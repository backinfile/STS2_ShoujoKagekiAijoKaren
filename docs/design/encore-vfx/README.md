## 当前结论

Shiv 使用一枚渐变尖刃与 GPU 拖尾，先飞行，约 0.15 秒后启动命中尖核、火花、闪花和薄烟。专属六个发射器的 amount 合计 14，不包含拖尾几何、通用伤害反馈及并发。
之前展示的 shiv_simple 属于调试素材；活动场景实际引用 dagger_spray_single，已更正。
原创华丽化建议保留一枚主刃，飞行碎光增加到 12–18、命中火花 28–40，再追加 12–20 次级亮片和 6–10 末端亮点，专属合计 62–92。绯光贯刺、再燃灯屑、双光贯刺只改变配色与碎光外观。
