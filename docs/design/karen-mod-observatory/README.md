## 当前预览

页面按已核实的 Spire Codex 指标定义与 OP.GG 筛选结构重新设计。默认打开统计表，可切换横向对比图；保留原始对局、卡牌详情、CSV/JSON 和 PNG 导出。点击条目选中记录，通过行末箭头或“查看对局详情”按钮打开完整详情。页面内嵌14张项目卡图与合成记录，可离线打开，无新增外部运行依赖。

- 基础指标：选取率、曾持有胜率、持有覆盖率，分别显示对应分子、分母和单位。
- 原始计数：提供次数、选中次数、持有席位、胜利/未胜席位；详情包含分幕选取率、来源张数和相关对局。
- 样本筛选：时间、版本、进阶、人数、游戏模式；默认排除前5层放弃，也可选择全部记录。
- 卡牌筛选：类型、基础费用、稀有度、卡名/模型 ID；不改变覆盖率的全部席位分母。
- 统计表与图共用筛选和排序；列头可排序。无样本显示“—”，提供但未选中可显示真实0%。
- 对局记录保留被排除的记录与原始 JSON。结果筛选仅用于对局列表。
- 规则和参考链接按需打开。本轮不处理耗尽统计，也不加入未经验证的评分或收益指标。

当前有168条对局记录、3,015个永久实例、4,241条原始事件。每局示例只含一个华恋席位；其他队友不进入华恋统计。默认近7天收到84局，排除1条前5层放弃后统计83席位。所有记录和接收状态均为模拟，未接入真实玩家数据、游戏或服务器。

## 对局详情

[打开示例对局](index.html#view=runs&run=KRN-0007&floor=28)

- 沿用原版 `NRunHistory`、`NMapPointHistory`、`NDeckHistory` 的顶部状态、分幕路线、遗物及卡牌结构；使用原版楼层图标、项目华恋头像、遗物和药水图片。新增17张内嵌资源，仍可离线打开。
- 点击对局行只选中记录；通过行末箭头、详情按钮或卡牌的相关对局进入完整详情。支持前后对局、楼层选择、奖励选项、卡牌获取楼层联动、原始 JSON、下载和链接刷新恢复；返回时保留对局选中及列表页码。
- 华恋专属展示对齐 [历史记录补丁](../../../src/Core/Patches/RunHistoryShinePatch.cs)：终局卡组与耗尽牌堆分列，卡牌按模型和升级状态分组。不记录剩余闪耀值，预览数据及导出中也不包含这些字段。
- 卡牌可查看每个永久实例的来源、获取楼层和离开牌组楼层；路线高亮对应获取楼层。楼层详情展示奖励、获取卡牌、遗物和牌组变化，不设置额外的“华恋记录”机制列表。
- 每局仍只展示采集到的华恋席位；没有其他队友的卡组或状态。不生成不存在的终局战斗牌堆快照。
- 当前历史页的种子、房间、生命、金币、遗物和药水为确定性模拟补充字段，与既有示例卡牌实例、奖励选择和事件关联；导出放在 `history_preview` 中并标记 `synthetic: true`，不代表真实历史文件已保存这些内容。原有168局、3,015实例、4,241事件及统计口径保持不变。
- 桌面侧栏与手机底部详情面板；手机路线独立横向滚动，详情支持键盘焦点循环、Esc收起/返回与减少动画设置。

## 本轮定向验证

- JavaScript 语法、UTF-8、相对链接及无新增运行依赖检查。
- 42个指标的分母、范围、零分母；同席位多副本去重、提供但未选中、分幕加总检查。
- 默认83席位、全部记录84席位；早期死亡保留、晚期放弃计入未胜、早期放弃仅从统计中排除。
- 类型/费用/稀有度/搜索不改变覆盖分母；单卡 CSV 与图像构造范围一致。
- 浏览器核验样本规则、卡牌属性、人数/模式、排序、表/图、原始记录、规则与参考来源、导出、URL恢复及空结果。
- 桌面与390 px窄屏检查；卡牌窄屏详情、内部表格滚动与页面溢出检查。
- 对局详情新增检查：168局的楼层、奖励/事件覆盖及卡牌分组总数；模型/升级分组、空耗尽牌堆、终局生命及可重复生成检查。
- 浏览器核验卡牌/耗尽实例、获取及耗尽楼层跳转、遗物禁用、前后对局、返回选中、原始记录及下载；导出样例核对19张终局牌、2张耗尽牌和48层。
- 1440×1000桌面与390×844手机核验通过；手机无横向页面溢出、图片漏载，详情键盘焦点循环与Esc收起可用。控制台无错误/警告。
- 最新交互核验：桌面和手机点击条目只选中，箭头打开完整详情；原始JSON不含剩余闪耀及前后闪耀数值，机制列表已撤下。除明确移除的字段外，原有168局记录、实例、奖励、事件与统计结果逐项保持一致。
- 本轮仅执行相关定向验证；未运行游戏、完整联机矩阵或服务部署。
