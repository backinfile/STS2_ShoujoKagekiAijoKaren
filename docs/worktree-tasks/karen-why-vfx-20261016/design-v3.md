# 第三版：玩家周围的绸带与碎片

依据用户对第二版的反馈，保留 `preview-v2.png` 中的绸带方向，撤掉其红幕、窗景和背景光幕。

- 五条独立连续网格：宽弧、抬高的宽带、细长卷带、下方短尾和紧凑折钩。各自的高度、弧长、宽度、相位和速度不同；路径带有非圆形起伏，带面随时间收窄、展开。
- 所有路径以实际出牌玩家的可见 `%Bounds` 为锚点；按角色显示尺度缩放。深度为负的网格段绘制在角色后方，深度为正的段绘制在身前，公转时持续跨越两层。
- 24 个碎绸/尖片沿不同轨道翻转，42 个小光尘随轨道移动。短片与光尘使用独立材质，避免绸带 Shader 的 UV 边缘遮罩让无纹理碎片不可见。
- `sunset_silk.png` 仅提供轻微色彩与褶皱变化，外形与动态由网格控制；不再用整张 S 形贴图左右平移。绸带附近的小范围柔光随带身移动，没有独立背景。
- 选牌后仅在卡牌原位置与实际到达约定星时给小光点，沿用原生移牌，不再添加跨战场的大段运输绸带。格挡、牌数和虚空路由保持原生结算。
- 快速模式加速，瞬时模式跳过装饰；完成、连续施放替换、离开战斗时释放网格、独立层和音效。

实现拆分为 `NKarenWhyVfx.cs`（生命周期/锚点/真实卡牌观察）与 `NKarenWhyVfx.Orbit.cs`（轨道、网格和碎片）。测试观察器补充前后网格、深度穿行、轨道移动距离及有限数检查；画面仍需实机逐帧复核。
