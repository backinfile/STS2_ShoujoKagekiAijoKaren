# 第七版：匹配既有参考图

用户反馈“与参考图不符”。对照 `preview-v6.png` 和 `gameplay-v6.png`，差异是明确的：参考以宽幅、半透明的红色边缘柔光为基底，左下与右上有斜向曝光亮峰；实机则将另一张光斑逐边取样，压成窄条与局部火光，亮点还离开了参考的固定构图。

本版不更换参考图、不另立概念。内置 Imagegen 从同一 `preview-v6.png` 提取完整透明边缘层，清除全部游戏/UI/黑色 dimmer，仅保留参考的光色、斜向亮峰和柔和过渡。输出 `reference_border.png` 与参考同为 1672×941 RGBA，alpha 0–253，中央 alpha 为零，原 PNG 不做后期编辑。

删除第六版的 `edge_light.png` 和逐边拉伸/移动 Shader。新 Shader 对完整构图仅进行小幅 UV 流动与 ±6% 的曝光变化，不旋转、拆条、巡边或重排亮峰。首轮并排复核后压低暖色亮峰，补偿 alpha 提取丢失的低强度红色柔光肩部，使宽度更接近参考。按当前逻辑视口绘制，原生卡牌、文字和 HUD 保持前景；中央额外保持透明，按钮周围柔和避让。淡入淡出、查看战场隐藏、瞬时/空手跳过和中断清理保持原选牌生命周期。

验收重点改为参考与实机并排核对：左下/右上亮峰位置、斜向形状、红色柔光宽度、中央留空，以及实际连续动画。功能验证聚焦基础、升级、虚空、查看战场、选牌中窗口缩放和未确认时换战斗；格挡/移牌前后 MCP 截图与 `karen_check_hand` 继续保存并查看。此修改不改变卡牌机制，不扩大到全面多人测试。

`tools/vfx/why/compare_reference.py` 只拼排原始参考与实机截图，并记录边缘 RGB 差分的粗略光峰质心/柔光宽度。原参考中的 UI 为生成图，不与原生游戏逐像素一致，指标不代表整幅画面相同。展示录像使用 `--selection-hold 4`，延长真实选牌停留以观察细微流动；不对游戏画面后期添加光影。
