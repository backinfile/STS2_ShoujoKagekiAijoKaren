# 保留静态构图，增强边缘内部流动

用户确认「现在静态状态是对的，需要让特效流动起来」。沿用第七版完整透明边缘层与原生 UI 层次，只修改 Shader 动画。

## 运动

- 用屏幕中心的环向坐标驱动波形与移动亮峰，顺时针沿屏幕边缘传播。原贴图里的左下、右上斜向曝光保留各自位置。
- 边缘切向位移由两种速度的连续波形叠加，法向位移由平滑流动噪声控制。角度噪声通过圆周坐标取样，避免角度跨越 ±π 时产生接缝。
- 奶油色亮部中有持续推进的高光波峰；两层不同速度的噪声推动红雾密度。轮廓、亮峰、雾层分别变化，流动在手牌完全不操作时仍能辨认。
- 继续使用逻辑 UI 视口尺寸和宽高比校正，中央透明带及按钮范围遮罩保持原样。

## 范围

生产代码只更改 `materials/vfx/karen_why_edge_light.gdshader`。`reference_border.png` 与 C# 节点、选牌时机、0.38 秒淡入/0.32 秒消散、查看战场隐藏、原生输入与牌堆路由均不变。没有新美术文件或场景资源。

验证器新增 `--no-recording`，让需要多次 PNG 的空间分布、运动截图与手牌核查单独运行。展示录像使用已有 `--smooth-recording`，每段先保持 7 秒不选择，随后原生确认与移牌。
