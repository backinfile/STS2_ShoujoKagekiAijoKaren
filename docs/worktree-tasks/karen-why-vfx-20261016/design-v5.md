# 第五版：选择卡牌时环绕屏幕边缘

- `KarenWhy.OnPlay` 先结算原生格挡，然后只围住本卡 `PromisePileCmd.AddFromHand` 调用创建一个监听范围，finally 结束。先前新增的共享牌堆选牌观察回调全部撤销。
- `NKarenWhyVfx` 订阅实际 `NPlayerHand.ModeChanged`。真实进入手牌选择模式时才创建粒子，不在格挡、移牌或普通战斗状态播放。退出选择后淡出约 0.32 秒；空手/自动选择路径没有粒子，查看战场时隐藏，离开战斗立即释放。
- 效果节点是原生手牌选择 dimmer 之后的首个子节点，位于卡牌、标题、查看战场按钮与确认按钮之下，无 Control 输入面，不改动原生卡牌节点。
- 五个 GPU 发射器共 200 个实例（短绸 28、薄片/折片 32、光尘 140），沿屏幕四边不同内缩距离的圆角矩形顺时针移动。弧长参数保持经过直边与转角的速度连续，各粒子独立翻面、淡入淡出，不连接成整环。
- 上边位于顶部 HUD 下方，边缘带保留中央展示区；对确认与查看战场按钮的实际屏幕矩形增加透明间隙。用界面逻辑视口尺寸和按钮 GetGlobalTransformWithCanvas 锚定，窗口变化后更新。
- 第四版粒子图集原样复用，无新美术生成或后处理。卡牌数值、选择数量、约定/虚空路由继续使用原生命令。

定向验证新增查看战场、选择中调整窗口大小和选择未完成时切换战斗。观察器检查出现时机、层次、实际 GPU 边界运动与退出；录制延长选择停留，另保存粒子开/关的画面对照以复核边缘分布。
