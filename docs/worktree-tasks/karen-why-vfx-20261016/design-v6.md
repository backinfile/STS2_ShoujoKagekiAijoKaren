# 第六版：全新边缘光影

用户要求“不要用你之前做的内容了，你完全重做边缘特效”。因此删除第五版的贴图、粒子辅助类与粒子 Shader，不通过修改旧素材、颜色或轨道交差。

新的 Imagegen 预览将视觉改为电影镜头中的舞台漏光：红色柔光在屏幕外缘透入，几处暖白色光峰沿边缘掠过，光峰后的柔和回光增加层次。没有布条、碎片、光尘、完整线框或舞台背景。该设计是原创表现方向，不声称复刻原作某一镜头。

首轮纯函数试制仍偏细直，未作为交付。根据实机对照，额外用内置 Imagegen 新生成光斑纹理 `edge_light.png`（2048×768 RGBA，alpha 0–253，原 PNG 未加工）。新的 `canvas_item` Shader 在四边独立取样，以各自的曝光相位、宽度、位置与 UV 折射变化推动光影。光晕、亮峰、柔和光幕的内部细节来自新素材；中央区域 alpha 精确为零，未采样/变形战场画面。视口逻辑高度的 7%–11.5% 是向内衰减区，上方 HUD 减弱，确认与查看战场按钮范围透明。

只沿用本卡进入/退出原生选牌的生命周期边界和本地玩家判断，不改变格挡、选择上限和牌堆路由。无可选牌和瞬时模式跳过视觉。节点在原生 dimmer 之上、卡牌/标题/按钮之下，无鼠标和焦点输入。查看战场时隐藏，结束选择后 0.32 秒淡出。单个 ColorRect、一张约 6 MiB 的 RGBA8 纹理、零粒子实例。

验证仍使用隔离 KarenSTS2MCP 实机环境，覆盖基础/零选/升级/快速/瞬时/虚空/空手/连续/查看战场/窗口缩放/中断。新观察器核查材质时间推进、表面尺寸、输入忽略和清理；基础案例额外比较实际画面在 0.65 秒内的边缘变化与开关特效的边缘分布。没有把仅有时间参数变化当作最终动画证据。
