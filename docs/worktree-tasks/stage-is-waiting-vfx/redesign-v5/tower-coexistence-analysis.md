# 与约定之塔的共存调整分析

用户原话：这个特效和塔的特效冲突了，你分析下怎么调整比较好

范围：只读对照 411d197 的有牌、空堆及触发实机帧与实际源码；本轮未修改运行代码，未启动游戏、未合并。以下数值是下一版建议值，不是已实测结论。

## 现有冲突

1. **空间和轮廓相撞。** 六灯以胸前左右 62 个归一化单位为源点，展开落点横跨约 488 个单位；当前截图单位约 1.23，展开范围约 600 像素。塔位于华恋左后方，左侧三束光横切塔的栏杆、平台和走灯。红色光缝又与塔的红色支架混在一起，无法形成独立轮廓。
2. **两套常驻在同一区域讲述状态。** Karen 的塔即使空堆仍常驻；能力空堆又持续显示展开的六灯扇面。有牌时的新红色边缘和塔红色结构相似，空堆时增加的白色灯束容易被读成塔的照明，而非能力进入另一状态。
3. **移牌和回能同时出现高亮。** 塔数减少会设置 departure，保留真实卡牌轨迹及交接亮光；能力实际回能后立即放胸前爆发、六灯追光、塔到胸前再去能量槽的独立光流。角色、塔及 HUD 同时成为亮点。
4. **现有退让幅度很小且无法处理构图。** 本能力 SetCueStrength = eventLight × 0.55，局部 cue 的统一压暗系数为 0.16，单独达到峰值时只使塔装饰权重减小 0.088，即 8.8%。有牌/空堆的常驻还不会增加 AmbientWeight 的能力层数。只调 ZIndex 或全局亮度系数不能解决轮廓重叠。

## 推荐的视觉分工

**塔承担大型常驻布景及真实卡牌存取；本能力承担胸前的候场状态和获得能量的一次短演出。**

| 状态 | 推荐表现 |
| --- | --- |
| 有牌 | 胸前保持紧闭的小光缝/收束光心；常驻形状限于躯干附近；撤去大红色双翼和常驻外扩六灯 |
| 真正清空且回能 | 塔先保留最后一张牌的移出反馈；约 0.12–0.18 表现秒后胸前局部白光接手，一束主追光与淡辅光从人物右上方落下；胸前直接向真实能量槽送出光流 |
| 空堆 | 小光缝开启，保留开放的小面积冷白轮廓；没有持续外扩灯束和重复回能演出 |
| 补牌 | 光缝收束回有牌形态；由塔的原有真实入牌反馈承担主要运动 |

以上形态需要让有牌/空堆靠开合轮廓辨识，不能只降低/提高亮度。剧场版保留胸前白光、开门节奏和冷白舞台追光；六灯阵列如保留，只在打出短瞬间出现，不作为第二套常驻舞台。

## 空间、节奏与退让

- 常驻胸前形状参考当前 1280×720 实机，光心约 20–28 像素，开合边缘总宽约 60–90 像素；实际仍按角色尺寸缩放。
- 灯光以人物右上方的空域为来源，聚到胸肩附近，避免在塔所在左侧布一排灯。先修构图，再判断是否需要局部柔性避让；不靠整体搬动塔和角色来让位。
- 打出主光建议控制在约 0.6–0.8 秒，真实回能的主峰约 0.35–0.5 秒；短流可以继续到能量图标。延迟仅存在于视觉包络，不延迟 GainEnergy 或其他规则命令。
- 回能主峰期间，局部使塔的装饰走灯/平台泛光退到常态约 35%–50%，随后平滑恢复。塔体、数量、库存星和真实卡牌移出轨迹维持可读性。
- 不修改所有卡牌共用的全局 .16 系数来补偿这一张牌；若增加退让入口，应只作用于该玩家塔的装饰层。
- 连发时保持短主光包络平稳，逐次真实回能各自保留小光心反馈及 HUD 光流，不重复播放完整六灯打出序列。

本轮仅给出分析。实施后应使用 KarenSTS2MCP 针对有牌/空堆/补牌、最后一张真实移出、连续清空及缩放镜像检查：

- 有牌/空堆仅看角色局部即可辨识；
- 塔移出 → 胸前确认 → 能量槽的亮点有明确先后；
- 清理、Fast/Instant 和重复触发语义沿用原有约束。
