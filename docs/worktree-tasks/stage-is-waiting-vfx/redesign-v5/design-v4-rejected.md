# 当前版：有牌候场 / 空堆开演

用户选择：“选D，去掉底座部分”；后续要求：“去掉大五角星”。第二版实体剧场未获接受，旧设计与技术记录保存为 `*-v2-rejected.*`；旧台面与幕翼资源转入 `v2-rejected-assets/` 历史目录并排除 Godot 扫描。

## 机制与真实事件

仍是 2 费／升级 1 费的 Uncommon 能力牌，每层在约定牌堆清空时获得 1 能量。空虚模式重定向到 Draw；无限再生产不触发清空回能。规则、卡牌移动与去重不变。

成功增层时播放打出演出；只有真实 `PlayerCmd.GainEnergy` 完成且差值大于零时才播放触发。读档／新战斗重建与每回合恢复走静默路径。所有视觉都不阻塞规则结算。

## 演出分层

| 阶段 | 表现 |
| --- | --- |
| 打出／叠层 | 独立金色光丝由下向上展开，右上追光扫向华恋，红金星屑与闪点升起；约 2.35 秒收光 |
| 有牌常驻 | 两组光丝靠近角色两侧收拢，窄金色追光偏向真实牌堆位置，星屑慢速悬浮；基础光幕 42% |
| 空堆常驻 | 两组光丝向外拉开，中央露出更大的空间；暖白追光落到华恋，星屑向外升起；基础光幕 48% |
| 补入牌 | 0.72 表现秒收拢回候场；从当前姿态反向接续，不播放增能或抵达声 |
| 清空并实际回能 | 光幕重新提亮，追光汇聚，约定位置的光流经过角色区域后进入实际能量图标，抵达时小范围粒子与音效确认 |
| 连续触发 | 一个主体复用，追光汇聚不被每次事件重置；每次真实回能独立光流，最多 8 路，短发射器最多 18 组 |
| 快速／瞬时 | Fast 以 1.6 倍推进窗口和粒子；Instant 跳过创建并立即清理现有演出，结算保持原速 |
| 中断与静默恢复 | 移除／死亡／换场／战斗结束清理后景、HUD、声音与渲染事件订阅；静默恢复的初始透明度为 0，不出现全亮一帧 |

光幕与星屑在人物后方；追光以前后两层组合，前层只取 12% 强度，保持面部和服装清晰。星屑不遮挡血条或手牌。光束结束点在脚部上方并渐隐，光丝末端交错、互不连接；不绘制台面、大五角星、地面光池、圆环、脚灯或可见灯具。

`karen_waiting_star_curtain.gdshader` 生成 19 条独立错落光丝及向上的亮点，不使用水平连接图形。`karen_theatre_followspot.gdshader` 提供空气中渐隐的单束追光。每帧及渲染前读取角色 `%Bounds` 的完整画布变换，缩放／镜像／位移保持光幕及追光的正确尺寸与定位。

## 音效迭代

用户要求：“换个合适的音效，你分析分析”。当前加入三段同源的原创光幕提示，分别绑定成功增层、真实回能和实际能量图标抵达；常驻无声。文件、时长、增益、原声音的峰值差分析及主观试听边界见 [audio-analysis.md](audio-analysis.md)，统计见 [audio-analysis.json](audio-analysis.json)。声音最多 4 个播放器，密集反馈间隔 0.18 表现秒，跟随 Fast 变速，随主体中断清理。

## 两态迭代

最新用户要求保留原特效，并根据约定牌堆有牌/空堆设计不同状态。原版实机与源代码快照保存于 [preserved-light-curtain/](preserved-light-curtain/README.md)。当前两态方案及边界见 [state-design.md](state-design.md)，原生 imagegen 提示词与两态概念为 [state-imagegen-prompt.json](state-imagegen-prompt.json) 和 [state-design-imagegen.png](state-design-imagegen.png)。

状态从真实移牌钩子及时刷新，同时按帧只读核对有效牌堆数量，以覆盖模式切换。Void 使用实际抽牌堆计数。无限再演暂时为零时保留姿态，等待自动补牌，不伪造清空演出。静默恢复直接采用当前牌堆姿态。

定位通过 GetExistingPileCanvasPosition 只读取得现有节点，避免常驻特效在拆建或清理间隙创建新塔。Shader 按 19 条光丝的实际移动位置计算像素，避免拉开时被旧 UV 网格截断。打出与回能峰值仍使用原错落光幕布局，装饰继续由粒子承担。
