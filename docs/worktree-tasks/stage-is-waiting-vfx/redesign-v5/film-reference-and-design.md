- 4.5–4.9 秒：暗红纵深通道显露，中央华恋、胸前冷白光与本项目卡图一致。4.82 秒关键帧作为精确对照。
- 约 5.0 秒切镜：镜头转到门扉另一侧，门由中缝向两边打开，蓝白灯光空间显露，人物向镜头运动。不能把两个机位误写成同一扇门连续反转。

## 新设计的机制映射

| 游戏事件 / 状态 | 新表现 | 反馈约束 |
| --- | --- | --- |
| Power 实际增加 | 胸前冷白光出现，后台门扉短暂建立，再停在当前有效牌堆对应姿态 | 复用主体；不播放整段电影，不更换角色图 |
| 有牌 | 两片深红透光边缘收束在人物后方；胸前保留微弱光心；少量浮尘 | 由门扉动作抽象出的光缝；没有实体门片、层叠矩形框、底座或地面投影 |
| 真实清空并实际获得能量 | 光缝外开消隐，胸口光心短促扩展，六点冷白灯成组展开；粒子先由真实牌堆位置汇入人物，再到能量图标 | 由 OnPromisePileEmpty 完成 GainEnergy 后的实际差值触发 |
| 空堆常驻 | 红色透光边缘淡出，保留开放负空间和低亮冷白灯阵；胸前光心平静 | 不重复回能、不重复放声音、不持续强光 |
| 补牌 | 从当下开度收回候场姿态；灯束收窄、降低 | 只改变常驻状态，不制造回能事件 |
| 无限再演 / Void | 维持当前有效计数与事务语义 | 无限再演的中间零不闪开门；Void 使用实际抽牌堆 |

镜头中的真实舞台运动用于光束扫描和开门节奏；以卡牌机制决定状态的含义。不会把“有牌/空堆”解释为原片的官方剧情设定。

## 制作范围

主形仅为两片透光边缘和紧凑胸前光心。光束用 Shader，浮尘、短促碎光与回能尾迹用粒子。避免旧金色光幕和大量金色星屑，避免实体舞台底座、五角星、巨大招牌、列车或全屏白闪。常驻占据人物周围，触发暂时展开但不盖住敌人、手牌与血条。

第一张实体门片预览被自行剔除，主体过于像战场道具；第二张 film-light-aperture-preview.png 改为红色光缝、六点冷白追光与胸前光心，是本轮实现参考。预览属于内置 imagegen 合成，角色和 UI 有生成偏差，不作为实机截图。该预览已用于本轮运行实现，旧实机视频不作为新设计验收证据。


## 实机调整记录

- 首轮观察器把三行收束光束的总宽误设为小于 50；实际设计两侧最大偏移为 30，总宽为 60。修正为收束小于 65、展开大于 480，保留失败记录于本地 artifacts。
- 空堆打出时已经是展开姿态，不应要求再扫出一个全幅角度。修正为始终验证打出光强，有过收束姿态的主体额外验证扫动距离；空堆独立检查展开轮廓。
- 胸前点从外包围框估算改为真实角色 Sprite2D UV (0.50, 0.35)，共用角色画布与入场形变。
- 根据直接查看的 MCP 原始录像提高常驻光心、灯点和光缝辨识度，保留明显弱于打出/真实清空的峰值强度。

- 八次快速连发时，已确认的光扇保持展开以避免抖动；重复要求每个主体都扫过全幅角度不符合这个行为。扫动距离改由普通模式“从有牌打出到收束”场景专门验证；连续触发专门检查八次真实能量、独立光流及上限，不把避免抖动判为失败。

## 最终结果

已完成运行实现、两版各 38 份观察及生命周期专项。最终交付录像在独立视频副本使用 KarenSTS2MCP 70c9dc2 / NVENC 重录，两版各做 8 秒画面内时钟解码；审计画面不进入展示片。最终结果见 ../testing.md、../verification.json 和 ../showcase.mp4。
