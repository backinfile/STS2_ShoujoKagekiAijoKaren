- **有牌候场**：两组光丝在人物两侧收拢，窄金色追光偏向真实牌堆，星屑缓慢悬浮。
- **空堆开演**：光丝向外拉开，让出中央空间；暖白追光落在华恋，星屑升起。空堆保持期间不会重复回能。
