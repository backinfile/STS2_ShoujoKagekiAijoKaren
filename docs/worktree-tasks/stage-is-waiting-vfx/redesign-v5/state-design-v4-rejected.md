# 有牌候场 / 空堆开演

保留版本：preserved-light-curtain/，来源提交 9992f89，包含原实机视频、截图和主体代码/Shader快照。三段原创音效不改动。

- 有牌：两束金色光丝在角色两侧收拢，窄追光偏向真实约定牌堆，小星屑缓慢悬浮。
- 空堆：两束光丝向外拉开，中央留出更大空隙，暖白追光落到华恋，星屑向上散开；常驻静音。
- 真实清空回能：保留已选光幕与星屑演出、实际增能后的星光输送及抵达音效。保持空堆不会再次回能。
- 补入牌：从当前姿态连续收光回候场，不重播打出、回能或抵达音效。
- 状态读取 PromisePileManager.GetCount，Void 模式对齐抽牌堆。无限再演暂时为零时保留姿态，等待自动补牌，不伪造开演或回能。
- 0.72 表现秒切换，反向切换从当前姿态接续。打出/回能峰值使用原布局，结束后回到真实状态。Quiet restore 直接恢复实际姿态。
- 不新增底座、大五角星、地面光斑、实体灯具或布幕。

原生 imagegen 两态预览：state-design-imagegen.png。基于真实战斗截图编辑，图内 UI/计数属于设计合成，最终以 MCP 实测为准。
