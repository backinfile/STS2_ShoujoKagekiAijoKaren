## Result and changes

已重做为环绕原生能量图标的细光环，并实现真实创建过程：0–0.20 秒左右光点抵达，0.20–1.10 秒绕行留下两段弧，1.10–1.36 秒接合并转入巡游。不是完整环的淡入。

- 有牌时暖金双光巡游，空堆时较弱冷白单光；真实回能才短亮、提速并向内收光。
- 叠层保留现有主体并强化扫光，不擦掉重建；静默恢复首帧直接为完整环，无创建光点或打出声音。
- 细环与短尾由 Shader 生成，创建光点用 Sprite2D，装饰用少量 CpuParticles2D；图标和能量数字由原版维护，绘制在它们后方。
- 环绕只绑定本地玩家真实能量槽，跟随 UI 变换。没有胸前图案、竖直短追光、底座或大型星形。
