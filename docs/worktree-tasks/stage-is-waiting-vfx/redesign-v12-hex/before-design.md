# 能量图标环绕：打出时创建

用户原话：

> 不行，重新设计一个环绕能量icon的特效，打出时要求有一个动画来创建这个环绕特效

使用内置 imagegen 生成 [创建分镜](redesign-v9-orbit/orbit-creation-preview.png)，[完整提示词](redesign-v9-orbit/imagegen-prompt.json)。形状和动作继续参考现有分镜；亮核、彗尾、轨道间距与稀疏碎光保留。最新颜色以 [卡图配色分析](redesign-v11-card-palette/colour-analysis.md) 为依据，旧金色分镜保留作形状和动作参考。此前将这些主体压成暗细线的实现已被用户拒绝，偏差分析见 [分镜对照](redesign-v10-fidelity/analysis.md)。运行时由 Shader、Sprite 与粒子组合完成。

## 一次明确的创建过程

| 表现时间 | 动作 |
| --- | --- |
| 0.00–0.20 秒 | 两颗小光点从左右接近图标外侧；没有预先显示的完整环 |
| 0.20–1.10 秒 | 两颗光点沿相同方向各绕半圈，真实逐段留下弧线；Shader build 从 0 连续变到 1 |
| 1.10–1.36 秒 | 两段弧线接合，同一组带亮核和软光晕的光点继续巡游；少量粒子收尾 |
| 之后 | 完整细光环保持，光点缓慢巡游 |

这些时间从真实 Power 生效、创建节点开始计，不从 HTTP 出牌请求或卡牌飞行开始计。创建过程本身不改变能量数字。

## 牌堆两态与反馈

- 有牌：蔷薇红发光轨迹，双光点带短彗尾慢速巡游。
- 实际清空且真实增能：环绕短亮、巡游提速，少量短光从外圈向槽边收回；0.16 表现秒后开始确认，模型结算不等待表现。
- 空堆：环稍放宽，成为较弱的烟紫单光巡游；不重复回能。
- 补牌：0.60 表现秒内回到蔷薇红双光，不播放回能音。
- 叠层：复用完整环，强化扫光；不抹去主体，不再次创建另一层环。
- 静默恢复：首帧直接初始化完整环状态，不播放光点抵达、画弧或打出声音。

卡牌语义保持 2 费／升级 1 费的 Uncommon 能力，真正清空约定牌堆时每层获得 1 能量。Void 读取有效 Draw，无限再演中间零不触发。

## 组成与边界

- Shader 形成细环、两段独立画弧遮罩和巡游短尾；Sprite2D 的独立 Shader 表现两颗具有浅粉白亮核、蔷薇红／烟紫内晕和宽软外晕的光点，创建结束后保留；CpuParticles2D 提供沿创建路径留下的短碎光及 18 个常驻微粒。
- 环归一化半径 92／94，横向椭圆（Y=0.84），在真实能量槽外围留出与分镜接近的明确间隙，保持原图标和数字。
- 所有表现均位于原生 NEnergyCounter 的子层，排在 Layers 和 Label 之前，继承真实 UI 变换，鼠标穿透。只绑定本地玩家，不向角色或塔放置常驻图案。
- 不使用大五角星、底座、灯束、符文、进度分格或额外资源数字。
- 普通常驻 strength=0.82／0.58，事件峰值不超过 1.06；细环和短尾各自塑形，不将这个参数解释为实际像素亮度百分比。
- 使用原分镜作为目标，不再将降低亮度或隐藏光点视为完成；在同图标尺寸下对照头部、光晕、轨迹与间距。
- 最多 8 路真实回能光流、12 个短粒子发射器和 4 个声音；实际结算独立计数，表现上限不合并游戏事件。
- 既有三段原创短 WAV 保留；不新增与实际回能混淆的创建完成提示音。
- Fast 动画及音高 1.6 倍；Instant 不创建、已有表现立即清理。
- 创建中断、移除、死亡、换房、UI 隐藏及恢复都处理前后层和声音；取消半环后，静默恢复直接显示完整环，不从中断位置续写。

本次实机和对应构建保存在 artifacts/stage-is-waiting-card-palette/。当前配色构建已完成两版专项，见 testing.md、verification.json、card-palette-comparison.png 与 palette-showcase-detail.mp4。此前暗细环的代码、Shader、状态图与创建视频保留在 redesign-v10-fidelity/before-*。
