## Brief task plan

- 保留目前创建动画和椭圆形状，直接查看卡图、能力图标后调整配色。
- 有牌采用蔷薇红双光，空堆采用较弱烟紫单光；实际回能提亮为蓝白光。
- 去除两个 Shader 中的金色通道偏色与固定米黄核心，统一环、光点、粒子和光流。
- 双版本做配色、两态及生命周期专项，交付卡图对照与新配色原声实机，保持一个任务提交。

## Result and changes

已根据卡图的暗红通道、绯红服装及中央蓝白光改色：有牌 #F08AA3 蔷薇红，空堆 #BDA2B8 烟紫，真实回能 #E2F1FF 蓝白，光核 #FFF6FA 浅粉白。
这是对卡图的美术判断，颜色本身不增加机制；同时保留双光／单光、亮度与真实增能反馈的区分。
当前创建曲线、0.20–1.10 秒逐段画弧、92／94 椭圆轨道及叠层复用不变，能量数字仍由原版维护。
