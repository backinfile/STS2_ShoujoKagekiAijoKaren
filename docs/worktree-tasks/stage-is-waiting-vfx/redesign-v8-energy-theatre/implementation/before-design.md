# 塔与能力共存调整：贴身光缝与右上短追光

## 规则与依据

《舞台正在等待着》是 2 费／升级 1 费的 Uncommon 能力牌，每层在约定牌堆真实清空时获得 1 能量。非最终移出、已空牌堆、单纯增能、无限再演自动补牌均不冒充触发；Void 读取实际 Draw 计数。结算不等待表现。

剧场版对应卡图与连续镜头已在上一轮检索、下载并查看，参考 [电影分析](redesign-v5/film-reference-and-design.md) 与 [imagegen 预览](redesign-v5/film-light-aperture-preview.png)。本轮按用户“这个特效和塔的特效冲突了”“你修改下我看看”进行共存调整；[调整分析](redesign-v5/tower-coexistence-analysis.md)。不新增大型图像主体，改用现有 Shader、柔光纹理和粒子。

## 实际表现

| 时机 | 能力表现 | 塔的表现 |
| --- | --- | --- |
| 有牌常驻 | 胸前窄光缝收束；低亮细光心；无常驻外扩灯束 | 保持原有塔、牌数与走灯 |
| 空堆常驻 | 同一个局部光缝打开，冷白两缘和中央小光心；不冒充回能 | 保持真实零牌数 |
| 实际获得／叠层 | 胸前短闪，两束右上追光短暂落向角色；0.78 表现秒内收起 | 装饰灯在峰值压到 40%，随后恢复 |
| 真正清空且实际回能 | 确认后等 0.16 表现秒，再短闪、短追光与短音；0.20 秒起胸前直接流向真实能量槽，1.0 秒到达 | 真实移牌仍即时进行；不再叠加一条塔→胸前的假转运线 |
| 补牌 | 0.72 表现秒内收束，可从中间开度反向；不播放本能力回能音 | 原有入塔、牌数与真实卡牌轨迹保留 |
| 快速／瞬时 | Fast 动画及音高 1.6 倍；Instant 无表现 | 中断后装饰权重立即恢复 |
| 移除／死亡／换房／结束 | 退出主层、后层、HUD、粒子、声音与渲染回调；静默恢复直接读取真实姿态 | 不留下压灯状态 |

- 光缝范围为归一化 62×46，位于前景以免被角色盖住；着色器用窄暗边衬冷白唇线，在浅色衣服上仍能分辨。没有黑色实体门片。
- 追光仅两束：主束 64%，辅束为主束的 22%。源点都位于角色右上方，横向距离 178／228，避免穿过左侧塔的剪影；没有六灯扇面与悬空灯点。
- 胸前点来自真实 Sprite2D UV (0.50, 0.35)，应用角色当前完整画布变换及入场形变；BeforeDraw 跟进同帧变换。
- 10 个局部浮尘、短碎光、光流尾迹采用 CpuParticles2D。大型主体不靠逐帧全屏绘制；没有底座、大五角星或角色残影。
- 同时最多 8 路独立回能流、18 个短发射器、4 个声音播放器；每次实际增能独立计数，表现上限不改变游戏事件。
- 回能流先向右下弯，再进入本地能量槽，避开塔上半部与原有卡牌出口；仅本地玩家绘制 UI 光流。
- 塔只降低装饰走灯的透明度；塔本体、牌数、库存、真实转运和到达反馈保持原有结算。只访问已有塔，不为能力创建道具。
- 塔的退让绑定有效来源，旧节点退出不能清除替代节点的退让；来源隐藏、离树、排队释放时直接恢复。
- 三段既有原创短 WAV 保留；声音在实际反馈开始时播放，快速连发节流，中断立即停止。没有使用电影音乐或对白。
- 保留 KarenVfxComposition 接口，未修改主检出中正在进行的全局共存工作。

最终原声录像和双版本定向结果见 testing.md、verification.json、media-summary.json。
