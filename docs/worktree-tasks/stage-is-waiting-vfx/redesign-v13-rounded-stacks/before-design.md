# 沿能量图标六边循迹

用户：这个转圈修改为沿着能量icon走的六边形试试吧

[实际图标原图](redesign-v12-hex/energy-icon-reference.png) 具有上下平边、左右尖角的轮廓，具体场景及顶点设计见 [轮廓设计](redesign-v12-hex/design-notes.md)。

## 形状与运动

- 六个归一化顶点依次为 (1,0)、(0.5,1)、(-0.5,1)、(-1,0)、(-0.5,-1)、(0.5,-1)，匹配原生图标的高宽形态。
- 有牌半径 74、空堆 76，外围留小间隙。表现仍绑定原生 NEnergyCounter，位于 Layers 和 Label 后方。
- 斜边长度为 sqrt(1.25)，平边长度为 1，周长 6.472135955。按真实边长分配周长进度，光点沿直边经过角点，不再使用椭圆角坐标。
- Shader 计算最近边及其周长坐标，生成六边主轨迹、光晕、短尾、两段创建遮罩。Sprite 使用同一周长位置，粒子发射点沿六边分布。
- 回能流从六边轨迹向内收光，保留独立事件反馈与数量上限。

## 创建与状态

0.00–0.20 秒双光点由左右抵达；0.20–1.10 秒各沿三条边逐段创建；1.10–1.36 秒接合并转入持续循迹。
创建不改变能量数字。静默恢复直接显示完整六边形，不重播创建；叠层复用同一主体。

有牌时 #F08AA3 蔷薇双光，空堆 #BDA2B8 烟紫单光，真实回能提亮至 #E2F1FF，亮核 #FFF6FA。
配色继续依据 [卡图分析](redesign-v11-card-palette/colour-analysis.md)，不是新增机制。
普通强度 0.82／0.58、Fast 1.6 倍、Instant 不创建并清理；真实增能确认、UI 隐藏／恢复、移除／换房及创建中断规则保留。
