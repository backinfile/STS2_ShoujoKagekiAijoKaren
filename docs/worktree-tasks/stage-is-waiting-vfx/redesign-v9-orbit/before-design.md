# 方案 B：能量槽低亮短追光

用户选择 B，并要求“修改的更不显眼一些”。选定图为 [B 追光落点](redesign-v8-energy-theatre/B-local-followspots.png)，本次直接按实机大小降低常驻亮度与范围，不另生成一张容易夸大效果的图。

## 机制与表现

《舞台正在等待着》为 2 费／升级 1 费的 Uncommon 能力；真实清空约定牌堆时每层获得 1 能量。表现只读取有效牌堆状态和真实能量增量，不改卡牌结算。

| 情况 | 实际表现 |
| --- | --- |
| 打出／叠层 | 能量槽后方短暂柔亮，4 个微小碎光；同一个主体复用 |
| 有牌候场 | 两束低亮暖光分开，仅位于槽体上方 |
| 真正清空并回能 | 确认实际增量后等 0.16 表现秒，双束向内收；短光点沿约 39 个局部单位汇入槽后 |
| 空堆待续 | 留下一束更弱的冷白光，不重复回能或声音 |
| 补牌 | 0.60 表现秒内平滑分开回到双束，不播放回能声 |
| 快速／瞬时 | Fast 动画与音高 1.6 倍；Instant 不创建，已有主体和声音退出 |
| 中断／死亡／移除／换房 | 释放控制节点、能量槽子层、粒子、声音与绘制回调 |
| 静默恢复 | 直接采用真实牌堆姿态，不重播打出音效 |

## 比概念图更克制

- 每束归一化长度约 42–44，宽 14；按当前 1280×720 UI 缩放，长度约二十多像素。
- 有牌常驻 strength=0.085，空堆=0.055；所有事件使用最大值而非叠加，峰值不超过 0.255。
- 双束源点总间距 36；空堆间距 0，并将第二束淡到 0。
- 循环浮尘仅 3 个，常驻透明度系数 0.055；单次短碎光仅 4 个。
- 最多 8 路独立短光流、8 个短发射器、4 个声音；连发只限制表现，不合并实际结算。
- 沿用原创三段短音效，音量由 0.40／0.34／0.26 降至 0.28／0.22／0.16，实际回能才播放 pulse／arrival。

## 定位、层级与事件边界

- NKarenWaitingStageVfx 作为房间控制器管理 Power 生命周期；所有新绘制和粒子都位于真实 NEnergyCounter 的子节点中。
- 子层插在 counter 的 Layers 和 Label 之前，ZIndex=0。槽体与数字覆盖其内部，光束和碎光只在外部小范围显露；鼠标穿透。
- 直接继承能量槽 UI 的平移、缩放及画布变换；不再从角色、胸前、脚点或包围盒计算位置。
- 只为本地玩家的 Power 创建能量槽表现；不把远端玩家的回能绑定到本地计数器。缺少有效 UI 时隐藏表现。
- UI 隐藏时无可见粒子并停止正在播放的声音；UI 恢复后显示当前真实姿态。
- 真实确认后每次增能独立计时；回能曲线仅在能量槽附近，0.20–0.68 表现秒完成。数值由原版真实能量更新驱动。
- 删除了胸前光缝、光心、局部横耀、跨战场光流和角色背后的长追光。
- 不再注册全局退让或修改塔的装饰灯；本任务先前增加的塔退让接口已撤回至 main 原状。
- Void 读取实际 Draw 计数；无限再演自动补牌的中间零保留当前姿态，不伪造空堆触发。
