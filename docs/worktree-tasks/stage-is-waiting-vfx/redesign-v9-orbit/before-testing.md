## 实机画面与媒体

- 已查看正式版和测试版的有牌／空堆、打出与真实回能帧，以及实际 UI 变换和恢复截图。新增追光仅在槽上方小范围显露，原能量数字与槽内星屑保留。没有胸前光缝、角色光球或跨场光流。
- 常驻 3 个浮尘；单次短碎光 4 个；实际峰值 strength 不超过 0.255。束长归一化小于 45。限制独立光流 8、短发射器 8、声音 4。
- DLL／PCK 与录屏部署记录逐项哈希一致；当前构建包含 main afb661c 的已有特效修复。
- 最终合片 46.741 秒，保留真实 1280×720 主画面和 game_process 声音；说明与同帧能量槽局部 ×1.4 放在画面外。
- 正式版 28.97 fps；测试版 29.57 fps；均为 NVENC。八秒时钟审计各 240 帧，分别 235／239 个不同值，最长重复 0.067／0.067 秒，丢帧 0。
- 未检出超过 1 秒冻结。精确哈希、来源和清理见 media-summary.json；取帧时间见 state-frame-evidence.json。
- 18857／18858 隔离游戏进程退出，配置逐字节恢复，临时观察器移除，未抢占前台。共享开发游戏及 Steam 安装未修改。

## 复现与限制

证据：artifacts/stage-is-waiting-energy-b/，stable／beta 各 waiting-stage 系列及 capture-audit。
使用 build_dual_branch.ps1 构建；prepare.py 从先前已更新的 KarenSTS2MCP 隔离副本准备环境。
record.py 的 scenes=waiting-stage,waiting-stage-audio，开启 audit-capture；verify_waiting_stage.py 的 output、lifecycle-output、media-output 都指向本轮目录，开启 audio-check。
package_waiting_stage.py 使用 --energy-detail，仅在原始画面外增加同帧放大。
本轮实际变换检查为原生 UI 节点平移与缩放，未运行多分辨率或多人矩阵；远端玩家不能绑定本地能量槽由代码 LocalContext 守卫实现，不冒充联机实测。
