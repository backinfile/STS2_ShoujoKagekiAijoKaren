## imagegen 与资源

内置 imagegen 直接编辑一张真实 Karen 战斗截图生成 `imagegen-theatre-preview.png`，保留人物、塔、UI 的相对布局，作为场景比例参考。另生成两个真正带 Alpha 的主体：

- `images/vfx/waiting_stage/platform.png`：红毯、木质台口、细金边的浅椭圆实体台面。
- `images/vfx/waiting_stage/curtain_left.png`：一侧红绒幕翼；右侧在引擎镜像。

两图角落 Alpha 实测为 0；只画台面和布料，没有烘焙光束、粒子或闪点。完整提示词见 `imagegen-prompt.txt`。Godot Sprite Region 使用实际非透明范围定位，没有生成另一套处理后图片。

## 演出

| 阶段 | 表现 |
| --- | --- |
| 打出／叠层 | 台面由窄展开，幕翼向外打开；两盏可见灯头转向，从舞台两侧扫向人物，脚灯依次点亮。约 2.35 秒后收光 |
| 常驻 | 保留实体台面、低亮脚灯与暗幕翼；舞台区域少量缓慢浮尘，追光强度降至低档 |
| 清空并真实回能 | 追光重新扫场汇聚到华恋，地面光斑与少量浮尘加强；确认光先由约定位置进入舞台，再流向实际能量图标；到达后只做局部粒子和短音效 |
| 连续触发 | 复用一个舞台；已有追光汇聚过程中不被每次新事件反复打断。每次真实回能有独立光流，最多 8 路；短发射器最多 18 组 |
| 快速／瞬时 | Fast 动画速度 1.6 倍；Instant 不创建演出。模型结算不等待特效 |
| 中断与恢复 | Power 移除、死亡、换场、战斗结束释放后景／HUD／声音和渲染事件订阅；静默重建只恢复待命舞台 |

光束由独立 `karen_theatre_followspot.gdshader` 驱动，实体灯头、运动方向、光束末端和地面光斑共用实际源点与落点。两层光束分别在人物前后，前层只有后层 24% 强度。台面和布料在人物后方，血条与手牌由原生 UI 显示。渲染前从角色 `%Bounds` 完整变换重新定位，缩放／镜像／位移均保持舞台正向。
