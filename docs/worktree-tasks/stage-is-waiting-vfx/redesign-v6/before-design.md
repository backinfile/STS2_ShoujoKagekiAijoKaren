# 剧场版参考重制：胸前光心与六点冷白追光

## 规则与参考

本卡为 2 费／升级 1 费的 Uncommon 能力牌，每层在约定牌堆真实清空时获得 1 能量。非最终移出、已空牌堆、单纯获得能量与无限再演自动补牌均不能假造本能力的触发；Void 使用实际抽牌堆计数。卡牌规则与移牌流程不变。

已搜索 B 站对应切片，并使用官方 yt-dlp 下载匿名可访问的两段 480p 片段。主要参考 [再生产＋光恋对唱](https://www.bilibili.com/video/BV1g44y1s7VN/) 4.82 秒的卡图对应镜头、约 5 秒后的门扉镜头与 126–140 秒的成组冷白追光。下载来源、哈希、准确观察与推论区别见 [电影参考记录](redesign-v5/film-reference-and-design.md)。视频仅作为本地分析参考，没有进入 Mod。

## imagegen

使用内置 imagegen，以真实战斗截图和直接查看的电影帧作参考。第一张实体门片过于像道具，已剔除；[选定预览](redesign-v5/film-light-aperture-preview.png) 将门扉抽象为透光边缘、胸前光心与六点冷白灯阵。[完整提示词](redesign-v5/imagegen-prompts.json)。

生成图用于比例与运动轮廓，不能当作实机截图；运行实现始终使用现有角色、约定之塔与原生 UI。

## 表现与组成

| 时机 | 主体表现 | 装饰 / 反馈 |
| --- | --- | --- |
| 实际获得或叠加 Power | 胸前光心出现，六点冷白追光短暂扫开，然后回到真实牌堆对应姿态 | 少量冷白浮尘与现有短音效；复用同一主体 |
| 有牌常驻 | 两侧暗红透光边缘收束，灯束内收，胸前小面积低亮光心 | 不形成实体门片、舞台框、台面或地面光斑 |
| 真正清空且实际回能 | 光缝向外消隐，六束冷白光展开，胸前局部短闪；真实塔位置 → 胸前 → 实际能量图标 | 独立粒子尾迹、到达短反馈；每个实际回能事件独立计时 |
| 空堆常驻 | 光缝消失，保留开放负空间与低亮六灯扇面；光心平静 | 不持续强光，不重复回能或声音 |
| 补牌 | 0.72 表现秒内从当前开度收束；方向可随真实状态反转 | 不播放本能力的回能声 |
| 快速 / 瞬时 | Fast 速度 1.6 倍；Instant 不创建，已有主体退出 | 模型结算不等待表现 |
| 中断与恢复 | 移除、死亡、换房、战斗结束退出并释放前后层、HUD、粒子、声音和渲染回调 | 静默恢复直接采用真实状态，不重播打出 |

- 光缝由独立 karen_waiting_aperture.gdshader 生成两片透光边缘，不再使用旧金色星幕 Shader。
- 六束追光是六个独立 ColorRect / ShaderMaterial，全部位于角色后方。六个柔光灯点与它们共用源点；没有实体灯具。
- 胸前光心、局部晕光和极薄光学横线使用柔光纹理 Sprite2D；胸前点来自真实 Sprite2D 的 UV (0.50, 0.35)，经过角色当前完整画布变换及入场形变。角色施法、受击、缩放和镜像不会让光心滞留在包围框中央。
- 24 个循环浮尘与一次性碎光、回能尾迹使用 CpuParticles2D。没有大型五角星、金色星屑幕或残影。
- 现有三段原创短 WAV 和音频节流保留，没有截取电影歌曲或对白作为音效。以最终原声实机为实际音画结果，不声称已主观试听原片孤立音效。
- 最多 8 路回能流、18 个短发射器、4 个声音播放器；只淘汰表现，不合并或增加游戏事件。
- 定位只读已有约定之塔，不因常驻查询创建新塔；本地 UI 光流仅对本地玩家显示。
- KarenVfxComposition 继续提供其他表现的退让权重，不修改主检出正在进行的全局共存工作。

本轮验证与实机媒体已完成，见 testing.md、verification.json 与 showcase.mp4；历史版本仅保留为被否定的记录。
