# 依据卡图和能力图标调整配色

用户：修改下配色，你看看是否与这张牌契合

直接查看项目内卡图 images/packed/card_portraits/karen/karen_stage_is_waiting.png 和能力图标 images/powers/karen_stage_is_waiting_power.png。卡图以暗红通道、绯红服装为背景，中央亮光呈蓝白色；能力图标也突出蓝白亮光与粉红部件。

这些是从现有卡图作出的美术判断，不将颜色解释成额外机制：旧金色环虽容易读成增能，但缺少本卡暗红与中央冷光的联系。因此将有牌主体改为蔷薇红，空堆为低饱和烟紫，实际回能时提亮为冷白偏粉；白亮核保持清晰。空堆继续靠单光和较低亮度区分，不用纯红或深酒红压暗主体。

| 用途 | 调整后的颜色 | 依据 |
| --- | --- | --- |
| 有牌：环、双光点外晕、碎光 | #F08AA3 蔷薇红 | 呼应卡图绯红与能力图标粉色；外围偏浅以区别原生红能量图标 |
| 空堆：较弱单光 | #BDA2B8 烟紫灰 | 从红色退向低饱和冷色，表达待续，保留可见性 |
| 打出提亮／真实回能光流 | #E2F1FF 冷白偏蓝 | 呼应卡图中央蓝白光；反馈从现有主体提亮 |
| 独立光核 | #FFF6FA 极浅粉白 | 保留亮点与光晕层次 |

两个 Shader 原有的金色通道乘数与固定米黄色核心也一并去除，避免只改 C# 颜色后实机仍偏金。创建曲线、椭圆比例、数量、事件时序与能量结算均保持当前方案。本轮只针对配色、两态、实际回能和创建／触发中断复测；此前完整机制记录单独保留。

## 实机判断

已直接查看两版录屏：蔷薇色在蓝色战斗背景上呈较浅粉白，白亮核保留；空堆降低饱和度和亮度后呈偏灰紫单光。这样的红色系外晕与中央冷白亮点更接近卡图和能力图标，也与原生红能量图标保持明暗及间距区分。本判断基于实际帧，输入十六进制色值不等于加色叠加后的屏幕像素。
