## Result and changes

已实现圆角六边贴边轨迹，光点数量在所有牌堆状态下均等于真实能力层数。有牌光点缩放 1.15、强度 1；空堆缩放 0.72、强度 0.28；主体轮廓同步减弱。数字保持前景。增减层数平滑重排，打出时由实际层数对应的光点逐段创建，保留回能和原有配色。

两版各 24 份观察及生命周期检查通过。实测 1、2、3 层、3→2 减层、补牌／清空、回能 1／2／3、普通与 Fast、UI 变换、中断、Instant 与清理；未运行完整机制／多人／多分辨率矩阵。
