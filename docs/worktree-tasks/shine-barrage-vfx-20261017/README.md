### 玩家试用后的贯穿修订

- 原反馈：`不太对，特效应该“贯穿”敌人`。首版终点只是命中中心外约 22–67 个角色单位，未覆盖大体型目标的背侧，因此撤销以“命中点外小段延伸”表达贯穿的方案。
- 新行为：从实际目标完整视觉边界计算射线远侧出口；剑光头部在约 0.07 秒内穿过目标，继续到出口外 140 个角色单位。尾部随后跟随穿出，主体在 0.24 秒内淡去。命中星芒保留在接触处，碎光改为在背侧出口向前喷射。
- 生产改动限于 `NKarenShineBarrageVfx.cs` 与对应 Shader；卡牌伤害、命中次数、出牌／重播和闪耀规则不变。
- 修订验证保存在独立 `piercing` 目录，不覆盖首版结果；覆盖普通、升级、Fast、Instant、三次播放、变换姿态和提前击杀。探针增加“光尖越过目标最远轮廓”的实际帧观测；视频和关键帧仍需人工查看。
- 修订版正式／测试版各 7 项通过，共 14 项；每版观测到 39 个专属节点，主／子层最终全部释放。非击杀命中的光尖实际超出目标最远轮廓至少约 79.55 像素，普通体型约 117 像素；变换后的定位误差最大约 0.000061 像素。
- 当前 DLL／PCK 哈希与修订版验证记录一致；双版本构建 0 错误。两版战斗段没有新增异常或 Shader 错误；测试版 Common 预载前仍有 1 条既有 `Invalid Task ID` 启动诊断，原日志单独归档。非交互模式未另测；耗尽、第二幕、途中清理未在本轮重跑，首版结果仅作为历史。
- 已查看两版修订接触截图和原速连续帧，确认头部贯穿、尾部穿出及背侧碎光；各用例已保存 MCP 前后状态／截图及手牌检查，手牌模型／视图核对一致。当前仍未运行 full／多人矩阵。
