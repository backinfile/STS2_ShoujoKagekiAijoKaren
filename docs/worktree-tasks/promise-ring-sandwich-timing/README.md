## 计划

- 复现存牌时的圆环和感染与格挡的结算顺序。
- 定位各自的事件入口，在对应机制处修复并执行定向回归。

## 结果

- 再生产使用原生的移除出战斗命令替换约定牌堆中的卡牌。离堆通知曾让《过去与未来》与《燃烧吧燃烧吧》按取牌结算。现在这两个能力只处理仍属于牌堆的离堆卡牌。
- 《Banana午餐》改用 `BeforeSideTurnEnd`，生成三明治时触发的《信封》格挡会在手牌中的《感染》结算前生效。

## 定向验证

- 正式版 v0.107.1 和测试版 v0.113.0 在隔离单人战斗中均复现了旧行为。再生产替换旧牌与《观察情况》存牌后，各多触发 1 次圆环和 1 点临时力量。《感染》开始结算时格挡为 0，三明治随后入堆。
- 修复后，两版使用再生产替牌、《观察情况》存牌及《坠落》选牌入堆均新增 0 次圆环和 0 点临时力量。随后用《约定之塔》抽出 6 张和 5 张续演，每张都触发圆环、临时力量和燃烧标记，约定牌堆补足到 10 张。
- 两版用两层《信封》与一层《Banana午餐》回归，《感染》开始结算时已有 4 点格挡，三明治入堆 1 张。
- 已查看 MCP 移牌前后截图，并在动作稳定后通过 `karen_check_hand` 核对手牌模型与可见节点。两版游戏日志未检出错误或异常。
- Stable、Main（v0.111.1）和 Beta 的 ExportRelease 构建均通过。Main 仅验证编译。
