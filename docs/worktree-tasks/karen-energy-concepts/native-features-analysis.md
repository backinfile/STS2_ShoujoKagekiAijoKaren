## 可直接观察的轮廓特征

| 职业 | 主轮廓 | 主要识别参数 |
| --- | --- | --- |
| 铁甲战士 | 接近正八边形 | 边长比较接近，顶端有角，整体均匀饱满 |
| 静默猎手 | 上下有尖的六边形 | 左右近似对称，上下收尖，斜边长短不均 |
| 储君 | 八芒太阳形 | 宽短的外尖和较浅凹口围绕宽阔主体，中心没有被尖角挤窄 |
| 亡灵契约师 | 上下为平边、左右有角的六边形 | 平顶/平底与横向两尖主导识别，局部手绘破边不改变主几何 |
| 故障机器人 | 削角方形，实际也有八条主要边 | 上下左右四条长边、四个短削角，方形结构明显 |

**纠正此前记录：** 将静默猎手称为“五边形”不准确。它的下方也有一个顶点，应按主要转折理解为尖顶六边形。旧生成稿和原始提示词保留历史，本分析及今后的参考标注采用更正后的描述。

原版本身已有“同边数、不同外形”：静默与亡灵契约师都可分解为六条主边；铁甲与削角方形都可分解为八条主边。因此，“不与本体重复”应按整体外形判断，需同时检查顶点朝向、长短边分配、宽高比、削角程度及局部凹凸；不能只用边数作唯一判据，也不能据此认为所有同边数设计都足够不同。

## 共同特征

1. **整体占位接近 1:1。** 以卡费纹理 alpha > 128 的可见边界只读测量，五款宽高比分别约为 0.986、1.000、1.000、1.062、1.000。它们的外轮廓都集中在接近正方形的区域，不采用强烈横向拉长或上下截断的形状。这是资源测量结果，不是声称存在官方硬性美术规范。
2. **中心宽阔，视觉重量集中。** 外形围绕近圆的能量区域展开，边角落在外围，中央能够放置费用数字或 3/3。主体没有深腰、通孔或明显分裂成多个部分。
3. **基础几何经过比例调整。** 保持少数清楚的方向和转折，左右整体平衡。数学分类相同的形状仍可通过长短边与角的位置区别；不是每个职业对应一个绝对不同的边数。
4. **外沿负责区分，内部结构相近。** 暗轮廓与折边建立外壳，中心使用更亮的同色系或邻近色，配少量旋涡笔触。外壳有厚度，但没有附加完整的具象物件来承担职业识别。
5. **画法是粗线条、低频细节的手绘 UI。** 折边、阴影和笔触在缩小后仍能读出大关系；轮廓不必机械精确，局部破边不能压过主形。
6. **卡费与战斗版本共享识别结构，分别制作。** 卡费是 AtlasTexture 中的独立小图，真实控件为 64×64；战斗控件为 128×128，使用独立的 3 或 5 张图层。战斗实现不等同于把卡费 PNG 放大两倍。

## 战斗版本与数字关系

场景中的主底层与数字均保持中心位置；NEnergyCounter 逐帧旋转 RotationLayers 的子控件，数字是独立 Label。源码中非零能量的前两层转速为 30/60 度每秒，零能量为 5/10 度每秒。能量增加时前后粒子重启；零能量时图层置暗，文字变红。

这些结论来自场景与代码，未在本轮运行游戏确认观感。对照图中的战斗行仅为零旋转角静态叠层，不包含实时粒子、着色器和数字，不能代替实机动画证据。

## 前几轮的偏差

| 已否定方向 | 外轮廓偏差 |
| --- | --- |
| 皇冠、番茄 | 外形过早依赖具象物件；顶部突起或叶片让主体失去原版均衡几何块的比例 |
| 正/倒三角 | 长尖角占用外框，轮廓的方向性很强，中央可用区域和重心分布与本体不同 |
| 梯形 | 上下差异较大，容易读成底座或面板，主轮廓的径向均衡较弱 |
| 梭形、双瓣 | 横向拉长；双瓣还产生两块相连的体感，缺少一个完整能量团的集中感 |
| 半圆 | 截断一半的圆造成明显平底和偏扁占位 |
| 厚十字 | 深凹角与四个伸出部分主导外形，读成加号/标记而非完整能量块 |

以上为设计判断，用于解释已观察的差异，不推断用户未说明的具体喜好。

## 后续设计标准

保留接近 1:1 的整体占位、一个宽阔完整的中心和少数清楚的外沿特征；先以灰色剪影与五职业并排，在小尺寸下判断是否同属一套 UI、是否与某一职业过于接近。配色、切面和尺寸固定，先验证轮廓，再进入新一轮材料与场景呈现。当前没有获选方案，本轮不追加新方案。

## 复现

设置 KAREN_NATIVE_RAW 为本地本体提取根目录，并按已有预览脚本配置 Node、Playwright 和 KAREN_PREVIEW_BROWSER，然后在本目录运行：

    node render-native-analysis.cjs

源文件使用 res:// 路径记录于 native-features-sources.json。主要读取 scenes/combat/energy_counters/*_energy_counter.tscn、src/Core/Nodes/Combat/NEnergyCounter.cs、images/atlases/ui_atlas.sprites/card/energy_*.tres 与独立的 combat/energy_counters 图层。
