### 共享绘制优化

- 接力星形完整填充十个顶点，低档连续曲线重新分段；飘带端点对浮点误差钳零。
- 等待舞台缓存有效能量计数器／图标，把呈现集中在 FramePreDraw；同一帧重复采帧复用姿态，晚到 Hook、层数及图标变换仍会使缓存失效。
- 共享光带保留逐段 halo／核心／细线的透明顺序，一条光带合为一次 Canvas 三角形提交，复用相邻路径采样与法线。
- 唤醒与接力复用实例顶点、颜色及固定索引／UV，直接提交 Canvas 三角形；取消逐次创建数组与重建 ArrayMesh 表面。
- Position 0 保留 12 段柔边，每个光锥合为一次提交，复用几何缓冲。
- 能量轮廓 Shader 的 RingVisual 在当前场景处于隐藏状态（两版实测为 false），保留其实现；本轮没有增加距离查找纹理。审查中的第二批候选未扩展实施。
