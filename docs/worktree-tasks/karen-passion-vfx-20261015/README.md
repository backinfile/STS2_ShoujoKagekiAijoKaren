### 实现

- `KarenPassion.OnPlay` 调用新增 `NKarenPassionCardVfx.Play(Owner)`，随后执行原有 `ExtraRewardCmd.AddRelicReward`。费用、闪耀、游戏规则随机流、奖励登记及战后发放逻辑保持原样，演出不增加规则等待。
- `NKarenPassionCardVfx` 使用全视口归一化坐标绘制金红星点、短拖尾及柔光；初始 252 枚，连续出牌追加到最多 320 枚，每位玩家仅一个粒子场。前后景分别挂在原生战斗 VFX 容器。普通单次约 2.1 秒，Fast 以 1.6 倍推进，Instant 跳过。
- 粒子对角色及下方 Buff 行保留低亮度区域，区域内透明度权重为 0.1，并降低顶部 HUD、底部手牌位置亮度；没有输入控件。窗口尺寸变化按当前视口重算。
- 保留 `KarenPassionPower.AfterPowerAmountChanged` 独立正增量钩子及 `NKarenPassionVfx`：角色肩侧显出已有 Buff 图标，少量金红星屑收向同一 Power 实例的真实图标，并显示本次 `+N`。普通约 1.05 秒，Fast 约 0.65 秒，Instant 跳过；连续增量最多保留 3 枚短脉冲。
- 卡牌粒子不依赖 Power 存在，Buff 反馈不依赖卡牌来源；各自拥有声音和节点寿命。移除 Buff 只停止 Buff 反馈，粒子自然完成；战斗结束、死亡、退树时均释放，前后景无遗留。
- `generate_audio.py` 保留原 0.32 秒增益提示音，另生成 0.74 秒轻盈粒子音；连续出牌的粒子音限频 0.35 秒，不重置 Buff 音效。
