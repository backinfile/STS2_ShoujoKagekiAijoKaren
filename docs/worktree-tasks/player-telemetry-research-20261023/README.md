## Brief task plan

1. 搜索中英文公开项目、战绩站、统计 Mod 和官方/作者文档，核对可复用能力与边界。
2. 阅读当前 Karen 上传与历史数据实现，以及相关本地服务源码，区分已有功能、缺口和设计建议。
3. 在 docs/research/ 保存带来源的调研、指标口径、架构与分阶段建议；仅修改文档。
4. 核验来源及文档，整合为一个本地提交，同步原 main；按用户选择保留任务分支及工作树。

5. 根据调研制作离线可打开、明确使用模拟数据的开发者 HTML 看板；验证筛选、详情、导出、桌面/窄屏与控制台。

最新视觉方向：暖纸白底、墨色文字与克制的墨绿选中态，横向导航、连续记录表和固定资料栏。

最新内容结构：样本概况 → 卡牌统计 / 对局记录 → 所选样本详情；统计表为默认入口，对比图、规则、来源和原始 JSON 按需打开。

最新交互方向：筛选样本、筛选卡牌行、列头排序、选择行查看原始计数及相关对局、导出当前数据；图表和表格共用口径，窄屏使用详情对话框，尊重减少动画设置。

6. 根据新要求整体替换预览页面，聚焦数据收集观察；只执行语法、关键记录统计和桌面/窄屏交互所需的定向验证。

7. 参考本地数据服务的横向卡牌对比图，在卡牌页加入图表/表格切换、指标组、稀有度与排序、图片导出；保持原记录与实例口径，进行相关定向验证。

本轮视觉方向：沿用现有纸白与墨绿工作台，让卡牌逐行排列和统一百分比刻度构成对比主体。内容为指标选择、对比图及所选卡牌详情；行选中、悬停与图表切换提供轻量反馈，遵从减少动画设置。

8. 依据已核实的 Spire Codex / OP.GG / 17Lands 规则重做统计区：选取率、曾持有胜率、持有覆盖率和原始计数；显式样本规则，按席位与选牌机会分别计数。本轮不处理耗尽统计。

本轮视觉方向：继续沿用纸白与墨绿，改为密集统计表与轻量详情栏；内容以样本筛选、卡牌属性、统计表/对比图和原始对局构成；排序、行选中和窄屏详情保持轻量反馈。

9. 参考本地原版历史记录场景及 Karen 历史补丁，为已有对局增加完整详情界面；保留统计页，展示分幕路线、遗物、终局牌组、闪耀值与耗尽牌堆，支持楼层/卡牌详情和前后对局切换。

本轮视觉方向：深灰游戏背景、暖金标题、原版路线图标与华恋图片；顶部状态与日期、分幕路线、遗物及两类牌组构成主界面，右侧为所选楼层或卡牌详情。进入界面、节点高亮和卡牌悬停采用轻量反馈，尊重减少动画设置。

10. 按反馈将条目点击恢复为选中，通过显式按钮打开完整详情；移除剩余闪耀的采集、展示、导出和分组依据，撤下额外的“华恋记录”机制列表。验证数据保留、两个入口及桌面/手机交互，更新截图。

11. 按最新要求新建独立 Python/SQLite 上传及查询服务，使用现有预览的视觉方向制作真实数据页面；验证格式、幂等、缺失数据、安全边界和页面后，部署到 botyun 的独立目录及 IP HTTPS 虚拟主机。旧服务不复用、不导入旧历史。部署阶段保留任务分支；用户随后明确要求合并到 main，按快进集成执行并保留工作树。
