### 燃料音效最终版本

已将 `karen_fuel_ignite.wav` 替换为用户选中的 F1「火球爆炸」，源自 Blankened 的 Freesound 431174（CC0）。采用与试听相同的公开高质量 MP3，完整解码为 1.081905 秒、44.1 kHz 双声道 PCM 16 位 WAV；没有裁短、滤波、增益、变调或附加包络。Godot 导入使用未压缩 PCM，关闭裁切和归一化。`tools/vfx/prepare_fuel_ignition.py` 校验所选源文件哈希并重现格式转换，同目录的 `karen_fuel_ignite.CREDITS.txt` 记录作者、来源、许可和处理方式。

`KarenDropFuel.cs` 继续预加载该资源。`NKarenDropFuelVfx.cs` 将播放请求移至蓄力后段，目标比爆散提前 0.12 秒；短重播蓄力从开始就播放。`PlayBurstSound()` 的实例标记保证每次施放只播放一次，`Emit()` 保留 Instant 模式兜底。子节点 `AudioStreamPlayer` 继续使用原生 SFX 总线，首次音量 0.68、后续 0.40、音高 1，声音自然结束时释放；卡牌规则和视觉节奏不变。

以旧实录复现声音比可见爆散晚 110.3／99.9 毫秒的问题。新增 `tools/vfx/catalog/verify_fuel_audio_timing.py`，从真实画面识别牌框消失、从进程音轨匹配 F1，旧录制检查失败，新录制通过；正式版／测试版的声音起点现分别早 58.4／37.7 毫秒，让其后约 60 毫秒处的主冲击更接近画面爆开。
