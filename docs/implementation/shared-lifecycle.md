# 公共生命周期接入

Karen 要求 Core 1.2.0。小规模选项通过 `CardSelection.Choose` 使用原生选牌、联机同步与作用域标题，角色在取得结果后执行牌效。

`CardModelEx.CreateTransferCopy` 使用 Core 的永久转交流程，接收玩家在登记新牌时确定。`KarenSunlight` 与闪耀药水通过 `CardCopies.Acquire` 重新获得满余量永久牌及可选手牌实例；只有原生获得成功时才绑定永久来源。战斗临时复制通过 `ForCombat(..., TemporaryCopy)` 保留本场状态及独立预算。

`PromisePileManager` 统一拥有约定模式、`EffectivePile`、移牌生命周期、空堆通知、计数和补充。Void 模式将逻辑约定牌堆映射到抽牌堆。原生移牌完成后统一发送进入／移出钩子，刷新表现，并在真实空堆边界通知；交换手牌保留既有额外空堆触发规则。无限支援通过同一补充入口维持数量，使用重入保护。

`UpdatePowerAsync` 只刷新已存在的约定能力。初始化角色、进入模式或显式加入约定牌堆时才激活能力，其他角色的普通抽牌与自动出牌不会创建约定状态。自动出牌结束或异常时，仍滞留 Play 的牌回到有效约定牌堆。

选择标题补丁、全局抽牌自动出牌补丁和与 BaseLib 3.4.7 重复的进度补丁已移除。正式版与测试版均直接引用各自真实游戏程序集构建。
