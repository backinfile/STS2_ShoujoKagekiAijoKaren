| `src/ShoujoKagekiAijoKaren/GodotScripts/PromisePileSystem/Vfx/` | 塔、旧常驻、牌堆交接、燃料、塔桥、聚光及台词节点 |
| `src/ShoujoKagekiAijoKaren/GodotScripts/DisableRelicSystem/Vfx/`、`Vfx/` | 遗物预告／吸收、续演命中／消耗 |
| `src/Core/Audio/` | 短音、循环音、战斗音乐与原版音乐交接 |
| `scenes/`、`images/vfx/`、`materials/vfx/`、`shaders/`、`audio/` | 场景、纹理、材质、Shader 与音频资源 |

层级不是仅由一个 `ZIndex` 决定，首先受父容器／Canvas 约束：

1. 角色背后：塔、光环背面、角色风场、短演出的 `BackCombatVfxContainer` 子层。
2. 战斗前景：真实攻击、命中、角色短反馈，通常归 `CombatVfxContainer`。
3. 卡牌局部：`NCard.OverlayContainer` 内的燃烧、普通闪耀、临界提示、Position 0 卡顶标记。
4. 战斗 UI：交接尾迹、回能和牌堆图标；必须换算 Canvas 坐标。
5. 原生选牌界面：装饰放在 dimmer 之上、卡牌与按钮之下，`MouseFilter=Ignore`。
6. 过场：最后的台词使用 `NRun.GlobalUi` 高层覆盖，拥有独立音乐交接。

## 共存规则

### 亮度

统一入口：[KarenVfxComposition](../src/Core/PromisePileSystem/Vfx/KarenVfxComposition.cs)。

- 燃烧、过去与未来、再生产、觉醒叠加时，常驻装饰权重最低为 `.58`，再乘当前事件权重。
- 短期 cue 取最强抑制值：角色局部最多压低 `.16`，全舞台最多 `.28`。重播、多个角色、多个子层不重复连乘。
- 注册者自身可用 `except` 排除，前景真实命中／卡牌交接／HUD 结果不统一降亮度。
- 只有处于场景树中且实际可见的 cue 参与；节点自己或祖先排队释放时立即退出计算，恢复显示后重新参与。
- 新演出若添加常驻背景或大面积舞台光，在 `_Ready` 注册、按包络更新、`_ExitTree` 移除。纯局部接触和选牌提示不因“也是特效”而自动注册。

### 所有权与清理

- 卡牌节点复用时，`IsInstanceValid` 只能证明 Godot 对象存在，还必须核对 `Model`、父容器及显示状态。燃烧与闪耀在 `OnFreedToPool` 立即拆掉自己的 overlay。
- 原生卡牌的隐藏、颜色、材质、鼠标过滤及图标形变只在明确持有期间修改，释放时归还各自保存的状态。观察型尾迹不接管手牌布局。
- 跨背景／前景／UI 的一个演出，由主节点统一释放兄弟层、音效、信号、Tween 和等待完成源。
- 有真实命中或收益时才确认演出；不让固定计时器代替规则成功。视觉销毁必须解除等待，不能卡住出牌链。
- 能力图标通过 `KarenPowerVfxAnchor` 按实际 Power 身份定位。原生 NPower 占位场景即使 Ready 也可能尚未绑定 Model；需等 Container 接线完成，并排除隐藏、脱树和排队释放的节点，避免跨玩家扫到未绑定图标。
- 短音走游戏 SFX 总线，调用者增益只应用一次。战斗音乐由 `CombatBgmReplacementManager` 持有当前播放器和淡出播放器。
- 新音乐、过场或退出撤销旧淡出：停止旧播放器、杀旧 Tween，并使旧恢复请求失效。正常淡出完成后恢复原版音乐；重复 Stop 或换房兜底不能在淡出途中恢复。
- 替换音乐还绑定启动它的战斗房间；房间退树立即停止当前／淡出播放器并撤销旧恢复请求，新房间恢复自己的原生音乐。调试直接换场也不能把 Form BGM 带到下一场。
- 不调用原版 C# `NRunMusicController.StopMusic()` 来临时静音，避免卸载 act banks。只停底层 music event，恢复时先 `UpdateMusic`，同曲目缓存命中时补建缺失事件，再 `UpdateTrack → UpdateAmbience`。

### 速度与资源

- 不统一改动已有节拍。燃料普通／Fast 同节拍、唤醒 Instant 保留选择反馈、牌堆查看 Instant 显示静态装饰，都是当前代码的明确分支。
- 共享 Shader／纹理可以缓存，动态参数写入各演出的 ShaderMaterial；角色待机材质保持场景独立。

- 本页的“共存”是本 Mod 内部视觉生命周期约定。同版本多人矩阵与边界的实际覆盖见 [测试记录](testing/full-matrix-vfx-boundaries-2026-10-16.md)，不代表第三方工坊特效 Mod 任意组合已经验证。
